# 変化球の数と変化量 改修指示（投手の変化球 2本目）

## 目的

「投手の変化球」の改修の2本目。1本目（`変化球の種類と球速_改修指示.md`）で球種の種類を直したあと、**先発の球種の数**と**総変化量**を、年齢・コントロール・球速に合わせる。

1. **先発の球種の数**: 実在は、年長・コントロールの良い先発ほど球種が多い。4球種は25歳以上でコントロールの良い先発だけ。生成は年齢・コントロールとほぼ無関係で、30〜33歳はかえって2球種が多い。23歳以下の先発にも4球種がいる。
2. **先発の総変化量**: 実在は、球種が多いほど、また球速が速いほど総変化量が多い。生成はこの結びつきが弱い（球種数）か、逆向き（球速）になっている。
3. **救援の総変化量と球速**: 先発と同じ向きのずれが小さく残っているので、少しだけ直す。

救援の球種の数（#119 で球速に合わせたもの）と、球種の種類（1本目）は変えない。

**対象**: 架空球団用の日本人投手（`apply_fictional_pitcher_balance`）。ドラフト候補用・助っ人外国人用は変えない。

**前提**: 1本目（変化球の種類と球速）をマージした後の main で作業する。この指示書の試作は、1本目の試作を入れた状態で行った。1本目の最終の値で、2-1 の範囲に入るか確かめ直す。

## 1. 改修の内容

### 1-1. 先発の球種の数を年齢・コントロールで増減する（新しい処理 `fictional_pitch_count_by_age_control`）
- `apply_fictional_pitcher_balance` の中で、`fictional_reliever_pitch_count` のあと、1本目の `fictional_pitch_type_by_speed` の**前**に入れる（足した球の方向・名前は1本目の処理で引き直されるため）。**先発だけ**にかける。
- 乱数は新しい副乱数（`make_sub_rng(seed, "fictional_pitch_count_age_control_v1")`）。1人につき必ず3回引く（u、方向用、変化量用）。
- 使う値: 年齢 `age`、コントロールは最終の値（`control`）。

```
s = 0.37 × min(max(年齢 − 29, 0), 6) / 3 + 0.30 × (コントロール − 55) / 13
```

1. 第一球種が4つで、年齢が23歳以下かコントロールが50未満なら、変化量のいちばん小さい球を外して3つにする（`remove_extra_primary_pitches`。同じ方向の第二球種も外れる）。ここで終わり。
2. s > 0 で、第一球種が2つのとき: u < min(0.75, s) なら1つ足して3つにする。
3. s > 0 で、第一球種が3つのとき: 年齢が25歳以上、コントロールが55以上で、u < 0.08 × s なら1つ足して4つにする。
4. s < 0 で、第一球種が3つのとき: u < min(0.75, 0.15 × |s|) なら変化量のいちばん小さい球を外して2つにする。

- 足す球の方向: 持っていない方向から `DIRECTION_SELECTION_WEIGHTS` の重みで選ぶ（2回目の乱数）。名前は仮に、その方向でその投げ手が投げられる球種のうち `base_weight` がいちばん大きいものにする（1本目の処理で引き直される）。変化量は 1・2・3 を 30・40・30 の割合で選ぶ（3回目の乱数。`FICTIONAL_ADDED_PITCH_MOVEMENT_WEIGHTS` と同じ）。
- 4つにした場合、1本目の処理は方向を変えない（k=4）。名前だけ引き直す。

### 1-2. 総変化量の増減に、球種数と球速を加える（`fictional_movement_by_quality` を変える）
増減の段階の式に項を足す。乱数は今と同じく `rng.uniform(-0.5, 0.5)` を1回だけ引く（乱数の並びは変わらない）。段階は今と同じ −3〜+3 に収める。

**先発**:
```
q = 0.4 × (コントロール − 55) / 13 + 0.6 × (スタミナ − 57) / 11      （今は2つの平均）
段階 = round( 0.65 × q − 0.1 − 0.15
             + 0.40 × (第一球種の数 − 2.65)
             + 0.40 × (球速 − 151) / 4
             − 0.10 × (今の総変化量 − 6.5)
             + u )
```
- B を 0.8 から 0.65 に下げ、スタミナの重みを上げた。球種数・球速の項を足すと、コントロールとの相関と標準偏差が上がりすぎるため。
- 最後の項（今の総変化量を6.5に少し寄せる）は、標準偏差を判定の範囲（1.43〜1.83）に収めるために入れた。
- 第一球種の数・今の総変化量は、この処理に入った時点の値（1-1 と1本目のあと）。

**救援**: 今の式に `+ 0.15 × (球速 − 151) / 4` を足す。

- `fictional_movement_by_quality` に球速を渡す引数を足す（`apply_fictional_pitcher_balance` の `speed`）。19歳以下にこの処理をかけないのは今と同じ。

## 2. 判定

### 2-1. 新しい判定
`scripts/check_pitcher_rank_pitches.py`（球団生成300球団）に「先発の球種の数と総変化量」の節を足す。実在は1本目の `data/config/pitch_type_speed_real.json` に足す（`--build-real`）。誤差は異なる選手の数で出す。

| 項目 | 合格の範囲 |
|---|---|
| 先発の年齢帯（4帯）ごとの球種数の平均 | 実在±（誤差の2倍。ただし最低±0.10） |
| 先発のコントロール帯（4帯）ごとの球種数の平均 | 実在±（誤差の2倍。最低±0.10） |
| 23歳以下の先発の4球種 | 0.5%以下 |
| コントロール50未満の先発の4球種 | 0.5%以下 |
| 先発全体の4球種 | 1〜4% |
| 先発の総変化量×球速相関 | 0.05〜0.25 |
| 先発の総変化量×球種数相関 | 0.33〜0.53 |
| 先発の2球種・3球種の総変化量の平均 | 実在±0.3 |
| 154km以上の先発の総変化量 | 実在±（誤差の2倍） |
| 救援の総変化量×球速相関 | −0.05〜0.12 |

### 2-2. 既存の判定の扱い
- 総変化量の判定（`check_pitcher_control.py`、`check_fictional_balance.py` の参考表示）は**合格のまま**であること。とくに先発の標準偏差（1.43〜1.83）とスタミナとの相関（0.45以上）は余裕が小さいので、値を必ず書く。
- 動いてよい項目: 先発の変化球数、総変化量、特能（#130 の総変化量・球種数との結びつきを通して）、査定と、それを使う判定（戦力・背番号など）、#130 の特能と能力の差の判定（合格の範囲内で）。
- 動いてはいけない項目: 能力（球速・コントロール・スタミナなど）、救援の変化球数と球速帯ごとの球種数（#119）、1本目の判定、ランク特能、野手のすべて、ドラフト候補・外国人のすべて。動いた場合は、更新せずに報告して相談する。
- 判定の範囲は実在から決めたまま動かさない。合格にならない項目があれば、値と範囲を報告する。

### 2-3. 検証の進め方
- 調整中は、新しい判定と `check_pitcher_rank_pitches.py`・`check_pitcher_control.py`・`check_special_profile.py` だけを流す（`--quick` でも可）。
- 1-1 の係数（0.37・0.30・0.15・0.08）と 1-2 の係数（0.65・0.4・0.4・0.10・0.15）は、1本目の最終の値に合わせて調整してよい。変えたら理由を書く。
- 正式な規模の流しは1回（並列数2）。PC で流し、スナップショットは流し終えた結果から書き込む。

### 2-4. 変わらないことの確認
- 架空球団用の日本人投手: 能力・ランク特能が改修前と一致すること。救援の変化球数が一致すること。変わった項目（先発の変化球数、変化球、総変化量、特能、査定）を人数つきで一覧にする。
- 野手・外国人・ドラフト候補: 全項目一致（背番号を除く）。
- `tests/test_hash_independence.py` が通ること。全テストを流し切り、成功・失敗の件数を報告する（失敗0件にしてから報告する）。
