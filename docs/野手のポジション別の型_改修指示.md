# 野手のポジション別の型 改修指示

## 目的

架空球団用の日本人野手で、**ポジションごとの能力の型**を実在に合わせる。

前回（PR #114、打席の型）で、打席ごとの能力の差は実在に合った。残った大きなずれはポジションごとの型で、例えば次のようなもの。

- 一塁手のパワーが低く、弾道4が少ない（実在 32%、生成 14%）。
- 遊撃手のパワーが高すぎ、弾道3が多い（実在 28%、生成 43%）。
- 捕手の捕球・パワーが高すぎ、肩力が低い。
- 三塁手の捕球が低く、幅が広すぎる。

対象は架空球団用の日本人野手の**22歳以上**だけ（個別生成・球団生成の両方）。21歳以下、走力、打席のずらし、投手、外国人、ドラフト候補用は変えない。

**前提**: PR #114 をマージした後の main（9ae6881）で作業する。

球団生成300球団（seed 1〜300、`PYTHONHASHSEED=0`）の日本人野手と、実在（2024〜2026年版の日本人野手）を比べた。

| 一塁手 | パワー −4.11、ミート −2.29、捕球 −1.50 | −21.6 | −0.39 | −0.53 |
| 二塁手 | 肩力 −1.73、パワー +1.27、捕球 −1.01 | — | — | −0.40 |
| 三塁手 | 捕球 −4.71、パワー −1.69、守備力 −1.44 | −12.1 | — | — |
| 遊撃手 | パワー +3.20、ミート −1.09 | +8.2 | +0.28 | — |
| 外野手 | パワー −1.93、守備力 −0.82、肩力 +1.12 | — | — | −0.37 |

### 0-2. 幅（標準偏差の比、生成 ÷ 実在）が広すぎるもの
一塁手の守備力 1.34、三塁手の捕球 1.36・守備力 1.27、遊撃手のミート 1.25、外野手の捕球 1.22。

### 0-3. 原因
- `fictional_fielder_abilities` の相関の写しにはポジションごとの差（`FICTIONAL_FIELDER_POSITION_SHIFTS`）があるが、それだけでは実在の型まで届いていない。弾道はパワーから決め直しているため、ポジションごとの弾道の分かれ方も実在とずれる（パワーが同じでも、一塁手・三塁手は実在で弾道が高い）。

## 1. 改修の内容（`fictional_fielder_abilities` の中だけ）

### 1-1. ポジションの型の変換（22歳以上だけ）
- 打席のずらし（`FICTIONAL_FIELDER_BATS_SHIFTS`）の**後**、整数に丸める前に、ポジション・能力ごとに次の変換をかける。
  ```
  値 = C + K × (値 − C) + D
  ```
  - `C` は中心、`K` は幅の倍率（1なら幅は変えない）、`D` は平均のずらし。
- 21歳以下にはかけない（`check_age_profile.py` の若手の判定を崩さないため）。
- 定数は1か所にまとめる（例: `FICTIONAL_FIELDER_POSITION_TYPE_TRANSFORM`）。
- 既存の `FICTIONAL_FIELDER_POSITION_SHIFTS` は変えない（21歳以下にも効いているため）。

### 1-2. 弾道のポジション差（22歳以上だけ）
- 弾道を決める点数に、ポジションごとの足し引きを加える。
  ```
  score = power + young_bonus + 位置の足し引き + rng.gauss(0.0, FICTIONAL_TRAJECTORY_NOISE_SD)
  ```
- 21歳以下は足さない。定数は1か所にまとめる（例: `FICTIONAL_TRAJECTORY_POSITION_BONUS`）。

### 1-3. 乱数
- 新しい乱数は使わない（弾道の `gauss` は今と同じ1回）。能力で決まる特能・ランク特能の付け直しで乱数の引く回数が変わり、後の抽選がずれるのは、これまでと同じく受け入れる。変わった項目を一覧で報告する。

### 1-4. 試作した結果（出発点）

container の作業コピーで試作した（球団生成300球団、`PYTHONHASHSEED=0`）。**この値を出発点にして、2章の判定で微調整する**。

```
ポジションの型（[C, K, D]、22歳以上）:
  捕手:   パワー [53.4, 1, −2.9]、捕球 [52.2, 1, −5.0]、肩力 [71.1, 1, +1.9]
  一塁手: パワー [57.8, 1, +4.6]、ミート [43.7, 1, +2.5]、捕球 [48.0, 1, +1.6]、守備力 [47.3, 0.75, 0]
  二塁手: 肩力 [58.1, 1, +1.9]、パワー [51.8, 1, −1.4]、捕球 [54.2, 1, +1.1]
  三塁手: 捕球 [43.9, 0.74, +5.2]、パワー [57.6, 1, +1.9]、守備力 [48.1, 0.8, +1.6]
  遊撃手: パワー [49.3, 1, −3.6]、ミート [40.3, 0.8, +1.2]
  外野手: パワー [54.3, 1, +2.1]、守備力 [53.0, 1, +0.9]、肩力 [67.0, 1, −1.2]、捕球 [49.2, 0.82, +0.7]

弾道の足し引き（22歳以上）:
  一塁手 +3.0、三塁手 +2.3、捕手 −0.6、遊撃手 −1.9、二塁手 −2.3、外野手 −2.0
```

| 項目 | 改修前 | 試作 |
|---|---|---|
| 上の表で直した能力の平均のずれ | 最大 4.71 | すべて ±0.2 以内 |
| 弾道の平均のずれ（ポジションごと） | 最大 0.39 | すべて ±0.09 以内 |

試作で残った課題（正式版で確認・調整する）:
- **まだ残る能力のずれ**: 捕手 守備力 +0.90・ミート +0.63、二塁手 守備力 +0.69、遊撃手 肩力 +0.78、三塁手 肩力 −0.48。2-1 の範囲に入らない場合は、同じ表に項目を足して直してよい。
- **捕手の査定が +6.4 高い**。上の能力のずれと青特の数（+0.45）が原因。能力のずれを直した後も残る分は、青特の数のずれによるものとして報告する（今回は直さない）。
- 青特の数のポジション差（捕手 +0.45、一塁 −0.53、二塁 −0.40、外野 −0.37）は、試作では動かなかった。
- 球団の野手力はほぼ変わらない（306.2 → 306.6）。実在より高い件は今回は扱わない（4章）。`validate_team_mode.py` の判定に入っていることだけ確かめる。

## 2. 判定

### 2-1. 新しい判定（PR #114 で作った `check_fielder_batting.py` に節を追加する、または新しいスクリプト。球団生成300球団、22歳以上の日本人野手）
PR #110 の仕組み（「実在」の判定、誤差つきの合否、id）で作り、`run_checks.py` に組み込む。

| 項目 | 合格の範囲 |
|---|---|
| ポジション × 能力（ミート・パワー・肩力・守備力・捕球）の平均 | 実在±1.5 |
| 1-4 の表で直した能力の平均 | 実在±1.0 |
| ポジション × 能力の標準偏差の比（生成 ÷ 実在） | 0.85〜1.20 |
| ポジションごとの弾道の平均 | 実在±0.15 |
| ポジションごとの弾道の割合（弾道1〜4） | 実在±6ポイント |
| ポジションごとの査定の平均 | 実在±8（捕手が外れる場合は 1-4 の扱いで報告） |

- 人数の少ないポジションで誤差が大きい項目は、PR #110 の仕組みどおり誤差つきで判定する。
- 個別生成（架空球団用・野手5000人）は参考として同じ表を出す。

### 2-2. 既存の判定の扱い
- `run_checks.py` を正式な規模で、**8スクリプトすべてを単独で**流す（ほかの重い処理と並べない）。
  - 能力・弾道・特能・査定・戦力・背番号で「悪化」が出るのは想定内。悪化の一覧を全部確認し、**動いてよい項目／いけない項目**に分けて報告する。
  - 動いてよい項目だけ `--update-snapshot --only ... --reason` で更新する。まとめて全部を更新しない。
  - 動いてはいけない項目（投手・外国人・ドラフト候補・野手の走力・打席の左右差・21歳以下）が動いた場合は、更新せずに報告して相談する。
- 特に確認する既存の判定:
  - `check_fielder_batting.py` の打席の左右差（PR #114 の判定がそのまま合格すること）。
  - `check_fielder_speed.py`（走力は変えていないので全項目そのまま合格すること）。
  - `check_age_profile.py` の若手の判定（21歳以下は変えていないので、そのまま合格すること）。
  - `check_fictional_balance.py` の野手の判定（ミート・パワーの分布、弾道、特能との連動）。
  - `validate_team_mode.py` の戦力レベル (a)〜(f)、球団ごとの散らばり、総合力の中央、強力打線・守備重視の目安、背番号。
- 「固定」の基準値を更新する場合は、`--update-baselines --only` で項目を絞り、理由を付ける。

### 2-3. 変わらないことの確認
- 助っ人外国人用・ドラフト候補用の投手と野手、架空球団用の投手: seed 1〜1000 で完全に一致。
- 架空球団用の野手の21歳以下: 能力・弾道が改修前と完全に一致する。
- 架空球団用の野手の22歳以上: 名前・年齢・ポジション・投打・走力が改修前と一致する。変わった項目を人数つきで一覧にする。
- `tests/test_hash_independence.py` が通ること。
- テストの期待値は、架空球団用の野手と球団生成の分だけ、理由を書いて更新してよい。
- 全テストを流し切る（途中で止めない）。

- 球団の野手力が実在より高い件（`TEAM_BASE_CLASS_MULTIPLIERS` の野手の倍率）。別の改修で扱う。

- 走力（PR #113 のまま）、打席のずらし（PR #114 のまま）。
