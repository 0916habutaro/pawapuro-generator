# 変化球の種類と球速 改修指示（投手の変化球 1本目）

## 目的

「投手の変化球」の改修の1本目。**どの方向・どの球種の変化球を持つか**を、球速と投げ手に合わせる。

- 実在は、球速の速い投手ほどフォーク方向（SFF・Vスライダーなど）を持ち、シンカー方向・シュート方向が少ない。同じ方向の中でも、速い投手は Vスライダー・パワーカーブ・ナックルカーブ・ドロップカーブ、遅い投手はチェンジアップ・スローカーブ・カーブ・シンカー・Hシュートが多い。
- 生成は、球種の選び方が球速とほとんど結びついていない。どの球種も、持つ投手の球速は全体の平均±1km以内に収まっている。
- 保有率そのものも少しずれている。シンキングスプリットが多く（生成10.4%、実在3.6%）、カーブ・フォーク・SFF が少ない。

球種の数と変化量は変えない（2本目 `変化球の数と変化量_改修指示.md` で直す）。能力・特能も、この改修では直接は変えない。

**対象**: 架空球団用の日本人投手（`apply_fictional_pitcher_balance`）。球団生成と、架空球団用の個別生成の両方。ドラフト候補用・助っ人外国人用は変えない。

**前提**: PR #132 をマージした後の main（4f25a3b）で作業する。

## 1. 改修の内容

### 1-1. 新しい処理 `fictional_pitch_type_by_speed`
`apply_fictional_pitcher_balance` の中で、`fictional_reliever_pitch_count` のあと、`fictional_movement_by_quality` の前に入れる。乱数は**新しい副乱数**（`make_sub_rng(seed, "fictional_pitch_type_speed_v1")`）だけを使う。乱数を引く回数は球の数で変わってよい（専用の副乱数なので、ほかの抽選に影響しない）。

使う球速は、この時点の最終の球速（`speed`、若手の補正のあと）。

```
x = (球速 − 中心) / 4 を −2.5〜2.5 に収める。中心は 右投 152、左投 149。
```

**① 方向の組を引き直す**（第一球種の数 k が1〜3のとき。k=4 は方向を変えない）
- 組 S の重みは「方向の組の重み[投げ手][k][S] × exp(x × Σ_{d∈S} 方向の傾き[投げ手][d])」。k=1 は傾きをかけない。
- 今の方向の組と比べて、外れた方向と新しく入った方向を、どちらも方向の番号順に並べて1対1に対応させる。外れた方向の球（第一球種・第二球種とも）の方向を、対応する新しい方向に書き換える。**変化量はそのまま残す**。
- 残った方向の球はそのまま。

**② 第一球種の球種名を引き直す**（すべての第一球種）
- 方向 d・変化量 m の球について、候補は「その方向で投げ手が投げられる球種のうち、`min_movement ≤ m ≤ max_movement` のもの」。
- 重みは「球種の重み[投げ手][d][名前] × exp(x × 球種の傾き[名前]) × 変化量の起こりやすさ[名前][m]」（m は6で頭打ち）。
- 候補がないとき（ほぼ起きない）は、m を3以下に下げて候補を作り、選んだ球種の範囲に変化量を収める。

**③ 第二球種**
- 同じ方向の第一球種の名前を除き、`second_pitch_allowed` の球種から②と同じ重みで引き直す。変化量は第一球種の変化量以下に収める。候補がなければ第二球種を外す。
- 最後に `enforce_second_pitch_movement_order` をかける。

- ストレート系第二球種（ツーシームファストなど）は変えない。
- `fictional_pitcher_breaking_balls` の左右の付け替え（チェンジアップ系を左投手に寄せるなど）は、**消さずに残す**。共有の乱数を同じだけ進めるため。名前は②で引き直すので、付け替えの効果は②の表（投げ手ごと）で決まる。
- ナックルは表に入れない（実在の日本人は0人。今も右投手はフォークに替えている）。

### 1-2. 表（`docs/変化球の種類と球速_試作表.json`。実装では `data/config/fictional_pitch_type_speed.json` に置く）
表は実在（0-1）から作った。生成に合わせて動かしてはいない。

- **方向の組の重み**: 投げ手 × k（2・3）ごとに、条件つきロジット（組の重み W と方向ごとの傾き β を同時に最尤推定。β のスライダー方向は0）で求めた、x=0 のときの組の割合（%）。実在にない組には小さな値（0.04〜0.1%）が残る。k=1 は実在の1球種（右投手22人がすべてフォーク方向）に疑似カウント1を足した値（フォーク方向85、ほかは3〜4）を両投げ手で使う。
- **方向の傾き**（β、スライダー方向に対する値）:
  - 右投: カーブ方向 0.043、フォーク方向 **0.909**（誤差 0.16）、シンカー方向 0.129、シュート方向 −0.066
  - 左投: カーブ方向 0.234、フォーク方向 0.428（誤差 0.22）、シンカー方向 0.229、シュート方向 −0.155
- **球種の重み**: 投げ手 × 方向ごとの、x=0 のときの割合（%）。傾き（γ）は両投げ手で共通にして、人数の少ない左投手を補った（多項ロジット。γ に標準偏差1の事前分布をかけた）。おもな傾き: パワーカーブ +0.66、ファストチェンジ +0.86、シンキングスプリット +0.51、ナックルカーブ +0.39、シンキングツーシーム +0.32、スラーブ +0.28、Vスライダー +0.24、チェンジアップ **−0.79**、スローカーブ −0.50、シンカー（スクリュー）−0.50、Hシュート −0.39、カーブ −0.26、スライダー −0.11。
- **変化量の起こりやすさ**: 球種ごとの変化量1〜6の割合。実在の件数に、同じ方向の割合を3件分の重みで足して均した値。名前と変化量の結びつき（カーブは小さく、フォーク・SFF は大きいなど）を保つために使う。

**表を作るスクリプト**: `scripts/pitch_type_speed.py --build-real` を作り、0-1 の実在から表を作り直せるようにする（推定の方法は上のとおり。scipy の L-BFGS-B で十分）。試作表と小さな差が出るのはかまわない。差が大きい場合（傾きが0.1以上違うなど）は報告する。

## 2. 判定

### 2-1. 新しい判定
`scripts/check_pitcher_rank_pitches.py`（球団生成300球団）に「変化球の種類と球速」の節を足す。実在は 0-1 の表を `--build-real` で `data/config/pitch_type_speed_real.json` に書き出して使う。誤差は異なる選手の数で出す（`SE = √(p(1−p)/異なる選手の数)`）。

| 項目 | 合格の範囲 |
|---|---|
| 方向の保有率（右投手4帯 × フォーク・シンカー・スライダー方向、左投手4帯 × フォーク方向） | 実在±（誤差の2倍。ただし最低±6ポイント） |
| 全体の方向の保有率（5方向） | 実在±3ポイント |
| 速い投手の球種・遅い投手の球種（3帯） | 実在±（誤差の2倍。最低±6ポイント） |
| 球種の保有率（実在の保有率が2%以上の球種） | 実在±（誤差の2倍。最低±2.5ポイント） |
| シンキングスプリットの保有率 | 6%以下 |
| 持つ人の球速と全体の平均の差（先発。Vスライダー・SFF・チェンジアップ・スローカーブ） | 実在と同じ符号で、実在±1.5 |
| 方向の組（実在で3%以上の組） | 実在±3ポイント |

右投手の148以下のシュート方向・スライダー方向は、上の範囲から外れたら要注意として報告する（1-3 の残るずれ）。

### 2-2. 既存の判定の扱い
- 動いてよい項目: 変化球の名前に関わる判定（`check_fictional_balance.py` の変化球の節）、特能（変わったのは14人）、査定（60人）と、それを使う判定（戦力・背番号など）。
- 動いてはいけない項目: 能力（球速・コントロール・スタミナなど）、変化球数、総変化量の判定（平均・標準偏差・コントロールとスタミナとの相関・査定の上位と下位）、救援の球速帯ごとの球種数、野手のすべて、ドラフト候補・外国人のすべて。動いた場合は、更新せずに報告して相談する。
- `check_fictional_balance.py` の「右投手のスクリュー」「左投手のシンカー・Hシンカー」が0件のまま、チェンジアップ系の左右の判定が合格のままであること。
- 判定の範囲は実在から決めたまま動かさない。合格にならない項目があれば、値と範囲を報告する。

### 2-3. 検証の進め方
- 調整中は、新しい判定と `check_pitcher_rank_pitches.py`・`check_fictional_balance.py` だけを流す（`--quick` でも可）。
- 正式な規模の流しは1回（並列数2）。PC で流し、スナップショットは流し終えた結果から書き込む（#125〜#132 と同じやり方）。

### 2-4. 変わらないことの確認
- 架空球団用の日本人投手: 名前・年齢・能力・変化球数・方向以外の項目が改修前と一致すること。変化球の名前・方向・変化量、総変化量、特能、査定が変わった人数を一覧にする。
- 野手・外国人・ドラフト候補: 全項目一致（背番号を除く）。
- `tests/test_hash_independence.py` が通ること。全テストを流し切り、成功・失敗の件数を報告する（失敗0件にしてから報告する）。
