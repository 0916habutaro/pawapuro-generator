# 外国人投手 生成バランス 改修指示（パワプロ実在データ 2022〜2026 準拠）

ジェネレーターの「助っ人外国人用」投手生成（`category=助っ人外国人用`）を、実在の外国人投手の傾向に合わせて調整する。
野手については `外国人野手バランス_改修指示.md` を参照。

## 0. 分析の前提（v3：5シーズン版）

- 生成側：`pawapuro_players_filtered_202609301342.csv`（1000人、全員投手・海外プロ経由）
- 実在側：baseless.org の「デフォルト選手データ」ページ（各シーズンの最新版）。**外国人投手 延べ214人分**。

  | シーズン | 作品・版 | 投手 |

  | 2022 | eBASEBALLパワプロ2022 1.08版 | 43 |
  | 2023 | eBASEBALLパワプロ2022 1.13版 | 43 |

  | 2025 | パワプロ2024-2025 1.15版 | 44 |
  | 2026 | パワプロ2026-2027 デフォルト（`pawapuro_players_entry_route_2026.xlsx`） | 42 |

- 5シーズンとも **変化球（変化量つき）・特殊能力・ランク特能・起用法まで揃っている**。体格と年齢は2026だけ。
- 外国人の判定：カタカナ名の選手と、漢字名の外国人（王柏融・宋家豪・古林睿煬・孫易磊・林安可）。日本の学校からドラフトされた選手（アドゥワ・ケムナ・マルク〈石田健人マルク〉・阿部 など）は除外。
- 同じ選手が複数年に出てくる（延べ人数）。
- **2026で新しく入ったもの** は2026だけで比べる：
  - 球種：シンキングスプリット、ファストチェンジ、Dスライダー
  - 特能：ストライク先行、存在感、死球集中、火消し（キラー系は「西武キラー」など名前が変わった）
  - 2026でなくなった特能：シュート回転、威圧感、鉄腕 など → 生成では使わない
- **作品ごとに傾向が変わっている項目**（回復、クイック、特能の数）は、ゲーム本体に合わせて **2026寄り** の目標にしている。
- 下記の目標値は **目安** として扱う。

## 3. 変化球

**球種数の数え方**：変化球（`kind: breaking`）だけを数える。ストレートと、ツーシームファスト・ムービングファストなどのストレート系第二球種（`kind: second_fastball`）は数えない。同じ方向の2球種（例：スライダー＋カットボール）は2つと数える。例：スライダー・カーブ・ツーシームファスト → **2球種**（ツーシームありとして別に集計）。実在データの集計・チェッカーもこの定義。

## 5. ラベルの整合性

- **先発に `acquisition_role=ロングリリーフ` が131人いる**。先発の獲得目的は「先発候補／再生候補／左腕補強／若手育成」に限定する。
- **選手格が特殊能力に反映されていない**：大物実績者と保険級で、通常特能の数（3.6／3.4）も良いランク特能の割合（30%／25%）もほぼ同じ。選手格に応じて、特能の数と良い特能の比率を変える。
- **成長タイプが年齢と無関係**：早熟（very_early）の選手でも29歳以上が63%いる。30歳以上は early／normal を中心にし、very_late は26歳以下に限定するなど、年齢に応じた重みをつける。
- `若手育成` の最高年齢が35歳 → 27歳以下に限定する。
- `育成素材型` は1000人中1人しかいない。出現させるなら重みを見直す。

## 6. 確認方法（完了条件）

`python check_foreign_balance.py <生成CSV>` で全項目を自動判定できる（プロジェクトの `claude/check_foreign_balance.py`）。改修の途中でも毎回実行し、不合格が0になるまで繰り返すこと。

- [ ] 球速：どの1値にも15%以上集中しない。160〜162が10〜15%、163以上が0.5〜2.5%、150未満が5%以下
- [ ] 球速とコントロールの相関が −0.45〜−0.15、球速とスタミナの相関が −0.45〜−0.15、コントロールとスタミナの相関が +0.2〜+0.5
- [ ] コントロール20未満が0件
- [ ] スタミナ：先発の平均が57〜62、救援の平均が46〜50、救援で38未満が1%以下
- [ ] 身長の平均が188〜192、アンダースローが0件、サイドスローが4%以下
- [ ] 2球種が50〜60%、4球種が0件、ツーシームが33〜42%
