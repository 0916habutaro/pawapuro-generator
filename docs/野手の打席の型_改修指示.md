# 野手の打席の型（ミートの左右差ほか） 改修指示

## 目的

架空球団用の日本人野手で、**左打者と右打者の能力の違い**を実在に合わせる。

洗い出し（`claude/洗い出し結果_2026-10-06.md`）でいちばん大きかったずれは、**ミートの左右差**だった。実在は左打者のほうがミートが約5.7高いのに、生成はほぼ差がない。右打者のミートは合っていて、左打者だけが低い。日本人野手のミートの全体の不足（−2.4）は、ほぼこの分。

実在の左打者は、ミートだけでなく「ミート・守備力が高く、パワー・肩力がやや低い」という型を持っている。仕組みが同じなので、まとめて直す。

対象は架空球団用の日本人野手だけ（個別生成・球団生成の両方）。走力（PR #113 で直した）、投手、外国人、ドラフト候補用は変えない。

**前提**: PR #113 をマージした後の main（59da99c）で作業する。

---

## 0. 調査の結果

球団生成300球団（seed 1〜300、`PYTHONHASHSEED=0`）の日本人野手と、実在（2024〜2026年版の日本人野手）を比べた。ユーザーが画面で作った12球団でも同じ傾向だった（左打 40.2、右打 39.7）。

### 0-1. 打席ごとの能力

| 能力 | 生成 右打 | 生成 左打 | 生成 左−右 | 実在 右打 | 実在 左打 | 実在 左−右 |
|---|---|---|---|---|---|---|
| ミート | 39.61 | 39.77 | +0.16 | 39.45 | 45.15 | **+5.70** |
| パワー | 52.87 | 52.60 | −0.26 | 53.80 | 51.28 | **−2.51** |
| 走力 | 60.59 | 68.78 | +8.18 | 59.91 | 68.99 | +9.08 |
| 肩力 | 66.77 | 66.38 | −0.38 | 66.95 | 65.22 | −1.73 |
| 守備力 | 51.48 | 52.29 | +0.82 | 50.39 | 53.50 | **+3.11** |
| 捕球 | 48.23 | 48.11 | −0.12 | 47.98 | 49.22 | +1.24 |
| 弾道 | 2.67 | 2.68 | +0.01 | 2.68 | 2.50 | −0.18 |
| 査定 | 244.8 | 256.4 | +11.6 | 243.7 | 262.2 | +18.5 |
| 青特の数 | 2.29 | 2.34 | +0.05 | 2.21 | 2.82 | +0.61 |

- 走力の左右差は PR #113 で入った。ほかの能力には左右差がない。
- 両打は人数が少ない（実在1.3%）。今回は右打と同じ扱い（ずらしなし）でよい。

### 0-2. ミートの左右差は年版・ポジション・年齢によらない
- 年版: 2022 +6.1、2023 +4.1、2024 +6.0、2025 +5.2、2026 +5.9。
- ポジション（実在の左−右）: 一塁 +5.6、三塁 +5.1、外野 +5.0、捕手 +7.3、遊撃 +4.5、二塁 +1.7。
- 年齢: 21歳以下でも +3.5〜+4.1（実在2026年版と、2022〜2025年版の逆算年齢）。生成の21歳以下は −0.9。

### 0-3. 原因
- `fictional_fielder_abilities`（架空球団用の最後の補正）は、能力を相関の行列で実在に写しているが、打席を見ていない。走力だけは PR #113 で `fictional_speed_adjust` に打席のずらしが入った。

## 1. 改修の内容（`fictional_fielder_abilities` の中だけ）

### 1-1. 打席のずらし
- 若手の補正（`fictional_young_transform`）の**後**、整数に丸める前に、打席ごとのずらしを能力に足す。
- 打席は `batting_throwing` の末尾から2文字目（「左」「右」「両」）で判定する（PR #113 と同じ）。
- 定数は1か所にまとめる（例: `FICTIONAL_FIELDER_BATS_SHIFTS`）。22歳以上と21歳以下で別の表にする。
- 走力は対象外（PR #113 の `FICTIONAL_SPEED_BATS_SHIFTS` のまま）。

### 1-2. 22歳以上と21歳以下の違い
- **22歳以上**: 右打のミートは合っているので、主に左打を上げる（全体の平均も実在に近づく）。
- **21歳以下**: 若手の能力の判定（`check_age_profile.py`）の平均を崩さないよう、**左打を上げた分だけ右打を下げる**（平均を変えないずらし）。

### 1-3. 弾道
- 弾道はパワーから決め直しているので、パワーのずらしで自然に動く。弾道に直接のずらしは入れない。

### 1-4. 乱数
- 新しい乱数は使わない。能力で決まる特能・ランク特能の付け直しで乱数の引く回数が変わり、後の抽選がずれるのは、これまでと同じく受け入れる。変わった項目を一覧で報告する。

### 1-5. 試作した結果（出発点）

container の作業コピーで試作した（球団生成300球団、`PYTHONHASHSEED=0`）。**この値を出発点にして、2章の判定で微調整する**。

```
22歳以上:
  左打: ミート +5.4、パワー −1.3、守備力 +1.2、肩力 −1.2、捕球 +1.1
  右打: パワー +0.9、守備力 −1.1
  両打: なし
21歳以下（平均を変えない）:
  左打: ミート +2.6、パワー −1.2、守備力 +1.1
  右打: ミート −2.4、パワー +1.1、守備力 −1.0
```

| 項目 | 改修前 | 試作 | 実在 |
|---|---|---|---|
| ミート 右打／左打 | 39.61／39.77 | 39.34／44.84 | 39.45／45.15 |
| パワー 右打／左打 | 52.87／52.60 | 53.79／51.30 | 53.80／51.28 |
| 守備力 右打／左打 | 51.48／52.29 | 50.39／53.49 | 50.39／53.50 |
| 肩力 右打／左打 | 66.77／66.38 | 66.77／65.33 | 66.95／65.22 |
| 捕球 右打／左打 | 48.23／48.11 | 48.23／49.08 | 47.98／49.22 |
| 弾道 左−右 | +0.01 | −0.09 | −0.18 |
| 査定 左−右 | +11.6 | +15.9 | +18.5 |
| ミート 日本人全体 平均／標準偏差 | 39.67／— | 41.83／11.43 | 42.11／10.71 |
| ミート 左打 10%／中央／90% | 26／40／54（全体） | 30／45／59 | 33／44／60 |

ポジションごと（ミート、試作 → 実在）: 一塁 右41.3→43.3・左46.3→48.9、二塁 右43.5→45.3・左49.0→47.0、捕手 右36.6→35.5・左42.1→42.8、遊撃 右36.3→37.9・左41.4→42.4。ポジションごとのずれは、次の改修（野手のポジション別の型）で扱う。

試作で残った課題（正式版で確認・調整する）:
- **球団の野手力が上がる**（中央 302.9 → 306.2、実在 302.2）。左打の選手が実在どおりに強くなった結果だが、`validate_team_mode.py` の戦力レベル (b)「中位が実在±3%」、球団ごとの散らばり、総合力の中央（実在±2%）に入るか確認する。外れる場合は、勝手に倍率を変えずに報告して相談する。
- 青特の数の左右差（実在 +0.61、試作 +0.13）はほとんど縮まらない。今回は直さない（4章）。
- ミートの幅が少し広い（標準偏差 11.43、実在 10.71）。

## 2. 判定

### 2-1. 新しい判定（`scripts/check_fielder_speed.py` を `check_fielder_batting.py` のように広げるか、新しいスクリプト。球団生成300球団）
PR #110 の仕組み（「実在」の判定、誤差つきの合否、id）で作り、`run_checks.py` に組み込む。

| 項目 | 合格の範囲 |
|---|---|
| ミート・パワー・守備力・肩力・捕球の、右打・左打それぞれの平均 | 実在±1.0 |
| 同じ5能力の左−右 | 実在±1.0 |
| ミートの日本人全体の平均 | 42.11±0.8 |
| ミートの左打の 10%・中央・90% | 実在±3 |
| 弾道の左−右 | −0.18±0.12 |
| 21歳以下のミートの左−右 | +2.5〜+5.5 |

- 個別生成（架空球団用・野手5000人）は参考として同じ表を出す。

### 2-2. 既存の判定の扱い
- `run_checks.py` を正式な規模で流す。
  - 能力・特能・査定・戦力・背番号で「悪化」が出るのは想定内。悪化の一覧を全部確認し、**動いてよい項目／いけない項目**に分けて報告する。
  - 動いてよい項目だけ `--update-snapshot --only ... --reason` で更新する。
  - 動いてはいけない項目（投手・外国人・ドラフト候補・野手の走力）が動いた場合は、更新せずに報告して相談する。
- 特に確認する既存の判定:
  - `check_age_profile.py` の若手の判定（21歳以下のミート・パワー・守備力の平均と幅）。
  - `check_fielder_speed.py`（走力は変えていないので全項目そのまま合格すること）。
  - `check_fictional_balance.py` の野手の判定（ミート・パワーの分布、特能との連動）。
  - `validate_team_mode.py` の戦力レベル (a)〜(f)、球団ごとの散らばり、強力打線・守備重視の目安、背番号。
- 「固定」の基準値を更新する場合は、`--update-baselines --only` で項目を絞り、理由を付ける。

### 2-3. 変わらないことの確認
- 助っ人外国人用・ドラフト候補用の投手と野手、架空球団用の投手: seed 1〜1000 で完全に一致。
- 架空球団用の野手: 名前・年齢・ポジション・投打・走力が改修前と一致する。変わった項目を人数つきで一覧にする。
- `tests/test_hash_independence.py` が通ること。
- テストの期待値は、架空球団用の野手と球団生成の分だけ、理由を書いて更新してよい。

## 4. 今回やらないこと
- 青特の数の左右差（左打のほうが多い）。能力の左右差を入れた後に測り直し、残れば別に扱う。
- ポジションごとの能力の型（遊撃手のパワー・ミート、捕手の捕球、弾道のポジション差など）。次の改修で扱う。
- 走力（PR #113 のまま）。両打の扱い。
- 投手・外国人・ドラフト候補用。
