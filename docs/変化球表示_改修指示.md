# 変化球表示 改修指示（ゲーム画面準拠）

パワプロ能力表示ジェネレーターの「変化球チャート」部分を、実機（パワプロ2024系 能力画面）の見た目に合わせて改修する。
**対象は変化球チャートのみ。** 球速・コントロール・スタミナ等の他パーツには触れないこと。

## 0. 作業の進め方

1. まずリポジトリ内で変化球チャートの描画コード（DOM / SVG / Canvas のどれか）と、球種データ（球種名・方向・変化量）の定義箇所を特定し、構成を短く報告してから着手する。
2. 下記「仕様」を上から順に実装する。寸法は **セル間隔 `u`** を基準単位として比率で持たせ、既存の表示サイズに合わせて `u` を決めること（実機 1920px 幅スクショで `u = 16px`）。
3. 最後に「確認ケース」の全パターンを描画し、スクショで見比べて差異を報告する。
4. **アニメーションは実装しない。** 色は静的に固定する（後述）。

参考画像（実機スクショ）がある場合は `docs/reference/変化球/` 等に置いて参照すること。ファイル名が確認ケースに対応している。

## 1. 方向と左右反転

7方向：ストレート（上）／スライダー方向（横）／カーブ方向（斜め下）／フォーク方向（下）／シンカー方向（斜め下）／シュート方向（横）。

| 方向 | 右投げ | 左投げ |
|---|---|---|
| スライダー | 右横 | 左横 |
| カーブ | 右斜め下 | 左斜め下 |
| フォーク | 真下 | 真下 |
| シンカー | 左斜め下 | 右斜め下 |
| シュート | 左横 | 右横 |

- **左投げは左右反転が正しい。** 現状の反転処理は維持しつつ、バーだけでなく **ラベル配置ルール（§5）も左右対称に反転** されているか確認すること。

## 2. バーの構造（最優先の見た目差）

現状：角丸ブロックが離れて並んでいる → **1本の連続したバー** に変更。

- 外枠（フレーム）：連続した1本の図形、色 `#008FF5`
- 内側にセルを並べる。セル間はフレーム色の仕切り線で区切る
  - セル間隔 `u`、セル内寸 ≈ `0.75u`、仕切り ≈ `0.25u`
- バー太さ（単体）≈ `1.375u`
- セル数：**全方向 7 セル**。最外セルは矢じり形（ホームベース型の先端）の中に入る
- バー全長 ≈ `7.5u`（横・斜め・縦すべて同じ長さ）
- ボール外周からバー開始までの隙間 ≈ `0.75u`
- 空セルの色：中心側 `#0A96FF` → 先端側 `#42B5FF` へ段階的に明るくなる（7段で線形補間でよい）

## 3. 変化量セルの色（静的・位置固定）

現状：全セル同一オレンジ → **中心からの位置ごとに固定色**。変化量が n なら中心から 1〜n 番目のセルをこの色で塗る。

| 位置（中心から） | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| 色 | `#FF7E00` | `#FFC800` | `#FFDA00` | `#FFA700` | `#FF5C00` | `#FF1D00` | `#FF3100` |

※実機はこの色が流れるアニメーション。今回は上記の一コマで固定する。

## 4. ストレートの印と中心のボール

- ストレート印：**ホームベース型の五角形**（上向き）。フレーム `#008FF5`、中の塗り `#FF7E00`
  - 幅 ≈ `1.25u`、高さ ≈ `1.55u`、ボールの真上に配置
- ストレート系が **2球種**（ムービングファスト、ツーシームファスト等）の場合：五角形を **2つ横に連結した形**（幅 ≈ `1.8u`、中に塗りが2つ）。離れた三角形2つにはしない
- 中心ボール：**真円**（縦長にならないこと）。外径 ≈ `2.1u`、青リング `#008FF5` は細め（≈ `0.25u`）

## 5. ラベル配置（最優先の誤読対策）

### 5-1. 基本位置（各方向1球種のとき）
| 方向 | 位置 |
|---|---|
| ストレート | 五角形の真上 |
| 横（スライダー／シュート） | **バーの上**、外側寄せ（現状はバーの下 → 修正） |
| 斜め下（カーブ／シンカー） | バー先端の下、外側寄せ |
| 下（フォーク） | バー先端の真下、中央揃え |

### 5-2. 同一方向に2球種あるとき
1球種目 = 内側（上／中心寄り）の列、2球種目 = 外側の列。ラベルは **反対側に振り分ける**（2つを縦に積まない）。

| 方向 | 1球種目 | 2球種目 |
|---|---|---|
| 横 | バーの上 | バーの下 |
| 斜め | バーの外側・中ほど | バー先端の下 |
| 下 | バー先端の左下 | バー先端の右下 |

### 5-3. ストレート系が2球種のとき
- 「ストレート」を五角形の **左上**、2球種目を **右上** に配置
- 同時に横方向のラベルは1段下げて（五角形ラベルとバーの間に）重ならないようにする

### 5-4. 衝突回避
- フォーク方向が2球種で左右にラベルが出る場合、斜め方向のラベルは1段上にずらす（参考：確認ケース14）
- どのケースでも **ラベルがバーや他ラベルに重ならない** こと。現状、川辺・又吉のケースで「カットボール」「Hスライダー」が斜めバーに重なっているので必ず解消する

## 6. 2本並びバーの形状

別々のバーを2本並べるのではなく、**1つのフレームの中に細い列を2本** 入れる。

- 横2本：フレーム太さ ≈ `1.8u`（単体の約1.3倍）、内部を上下2列に分割
- 下2本：フレーム幅 ≈ `1.8u`、内部を左右2列、先端は矢じりが2つ並んだ形
- 斜め2本：同様に1フレーム2列。**2列の根元・先端・セル境界をそろえる（段違いにしない）**。根元が隣のバーに当たる場合は根元を外へ下げる（詳細は `斜め2列バー_修正指示.md`）
- 変化量は列ごとに独立して塗る（列ごとに §3 の位置色を適用）

## 7. 文字スタイル

- ウェイト：**標準（太字にしない）**
- 色：`#2177C0` 付近のくすんだ青
- サイズ ≈ `1.2u`
- 長い球種名（例：シンキングツーシーム、サークルチェンジ、シンキングスプリット）は **横方向に圧縮して** 所定幅に収める（`transform: scaleX()` や SVG `textLength` 等）。改行や省略記号にはしない
- 英字は全角で字間を空ける（例：`ＳＦＦ`）

## 8. 背景

- チャート枠の背景 `#EDF5F6`、枠は白い角丸

## 9. 球種名の表記（要確認・勝手に変えない）

- 現状の略称「Fチェンジ」「Cチェンジ」「Sツーシーム」「Pカーブ」は、実機では正式名（圧縮表示）の可能性がある。
- ストレート方向2球種目の「ツーシーム」は、実機では「ツーシームファスト」の可能性がある。
- **マスターデータの名称は変更せず**、該当箇所を一覧にして報告だけすること（修正はユーザー確認後）。

## 完了条件

- 確認ケース全件でラベルの重なりがゼロ

- 左投げで全要素が正しく左右反転している
- 他の能力表示パーツに差分がない
