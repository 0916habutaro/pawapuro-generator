# 能力との結びつき（助っ人外国人用）と奪三振の直し 改修指示

## 目的

3段階の3本目。PR #129（ランク特能）・#130（特能）で架空球団用の日本人に入れた「能力に合った選手が持つ」仕組みを、**助っ人外国人用**に入れる。あわせて、外国人のランク特能の形（A・G の端が多い）と、#130 から持ち越した日本人の奪三振を直す。

1. **外国人のランク特能の形**: 生成は A・G の端が多い（投手の回復 A 5.5%、実在0%。野手の対左投手 A 4.8%、実在0%）。全ランク特能の重みを実在の外国人に合わせ直す。
2. **外国人のランク特能と能力**: 回復・打たれ強さ（投手）、回復・送球（野手）を能力で傾ける（#129 と同じ）。
3. **外国人の特能と能力**: 25特能を能力の合成値で付け替える（#130 と同じ）。
4. **日本人の奪三振**: 奪三振は球速の帯で保有率を決めているので、#130 の付け替えの重みから球速を外し、総変化量だけにする。

対象は助っ人外国人用（個別生成・球団生成の外国人）と、架空球団用の日本人の奪三振だけ。ドラフト候補用、能力は変えない。

**前提**: PR #130 をマージした後の main（014b31a）で作業する。

## 2. 判定

### 2-1. 新しい判定（球団生成300球団、外国人）
PR #129 の `scripts/rank_ability.py`、#130 の `scripts/special_ability_link.py` に外国人の節を足す（実在の外国人の値を `--build-real` で作る）。誤差は異なる選手の数で出す。

### 2-2. 検証の進め方（PC の負荷を減らす）
- **PC で作業する**（外国人の名前のデータベースがクラウドにないため。今回は外国人そのものを変えるので必須）。
- 調整中は、`rank_ability.py`・`special_ability_link.py`・`check_foreign_balance.py`・`check_special_profile.py` だけを流す（`--quick` でも可）。
- 値が決まったら、変えていない区分（ドラフト候補用の投手・野手、架空球団用の日本人野手）が seed 1〜1000 で改修前と完全に一致することを確かめる。一致したら `check_draft_balance.py` は流さない。
- 外国人・架空球団用の投手・球団生成を使う判定は、正式な規模で1回流す。スナップショットは流し終えた結果から書き込む（PR #125〜#130 と同じやり方）。
- 並列数は2程度に下げる。

### 2-3. 既存の判定の扱い
- ランク特能・特能・査定・戦力・背番号で値が動くのは想定内。悪化の一覧を全部確認し、**動いてよい項目／いけない項目**に分けて報告する。動いてよい項目だけスナップショットを更新する。
- 動いてはいけない項目（能力、ドラフト候補、日本人野手の特能・ランク特能、日本人投手のランク特能）が動いた場合は、更新せずに報告して相談する。
- 特に確認する既存の判定: `check_foreign_balance.py` の外国人の特能・ランク特能・査定（外国人の判定93件、PR #121・#122）、#130 の新しい判定（奪三振の帯）、`validate_team_mode.py` の戦力・散らばり・背番号、投手と野手の強さの相関。
- 判定の範囲は実在から決めたまま動かさない。

### 2-4. 変わらないことの確認
- 外国人: 名前・年齢・ポジション・投打・能力・弾道・変化球・身長・体重が改修前と一致する。
- 架空球団用の日本人: 野手は全項目、投手は奪三振に関わる特能・査定以外が一致する。
- 変わった項目（ランク特能・特能・査定・背番号）を人数つきで一覧にする。
- `tests/test_hash_independence.py` が通ること。全テストを流し切り、成功・失敗の件数を報告する（失敗0件にしてから報告する）。
