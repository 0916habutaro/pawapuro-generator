# 投手のランク特能（役割の差）と救援の球種数 改修指示

## 目的

架空球団用の日本人投手について、次の2つを実在に合わせる。

1. **ランク特能の役割の差**: 実在は、先発のランク点が低く（−2.1）、救援が高い（+0.6）。生成はどちらも同じくらい（−0.5、−0.1）。ノビ・回復のランクの付き方が、先発と救援で同じになっているため。
2. **救援の変化球の数**: 生成は救援の変化球数が多い（2.52、実在 2.41）。実在は、球速の速い救援ほど球種が少なく、1球種の救援もいる（3.8%）。

対象は架空球団用の日本人投手（個別生成・球団生成の両方）。野手、外国人、ドラフト候補用は変えない。

**前提**: PR #118 をマージした後の main（2aa8949）で作業する。

## 1. 改修の内容

### 1-1. ノビ・回復の重みを役割で分ける
- `FICTIONAL_PITCHER_RANKED_WEIGHTS` に、ノビ・回復の先発用・救援用の重みを足す（例: `"ノビ_先発"`・`"ノビ_救援"`・`"回復_先発"`・`"回復_救援"`）。
- `fictional_ranked_specials` を呼ぶところの `weights_key` で、ノビ・回復は役割（先発、または中継ぎ・抑え＝救援）の重みを使う。対左打者の投げ手の分け方（`"対左打者_左投"`）はそのまま。
- 対左打者の重み（右投用・左投用とも）は、B を減らす。
- 重みを変えるだけで、乱数を引く回数は変えない。

### 1-2. 救援の球種数
- `fictional_pitcher_breaking_balls` の後、良し悪しによる変化量の増減（`fictional_movement_by_quality`）の前に、救援（中継ぎ・抑え）だけ、球速の帯ごとの確率で球種を減らす段階を足す。
  - 3球種の救援: 確率 `D3[帯]` で2球種にする。
  - そのあと2球種の救援: 確率 `D2[帯]` で1球種にする。
  - 減らすのは、変化量がいちばん小さい球（同じ方向の第二球種があれば一緒に外す）。変化量がいちばん大きい球（決め球）は残す。
- 乱数は**新しい名前空間の副乱数**（例: `make_sub_rng(seed, "fictional_reliever_pitch_count_v1")`）から、1人2回引く。今の乱数の並びを変えないため。
- 球種が減ると救援の総変化量が下がるので、`FICTIONAL_MOVEMENT_QUALITY["救援"]["O"]` を上げて戻す。
- 3球種目を足す割合（`FICTIONAL_THIRD_PITCH_ADD_RATE`）は変えない。

## 2. 判定

### 2-1. 新しい判定（球団生成300球団、架空球団用の日本人投手）
PR #110 の仕組み（「実在」の判定、誤差つきの合否、id）で作り、`run_checks.py` に組み込む。`scripts/check_pitcher_control.py` に節を足すか、新しいスクリプト。

| 項目 | 合格の範囲 |
|---|---|
| ランク点の合計 先発・救援 | 実在（2024〜2026）と実在（2026年版）の間 ±0.4 |
| ノビ・回復・対左打者のランク点 先発・救援 | 実在±0.3 |
| 救援の変化球数の平均 | 実在±0.05 |
| 救援の1球種の割合 | 2〜6% |
| 救援の変化球数 球速の帯ごと | 実在±0.10（人数の少ない帯は誤差つき） |
| 救援の総変化量の平均 | 実在±0.15 |

- 個別生成（架空球団用・投手5000人）は参考として同じ表を出す。

### 2-2. 既存の判定の扱い
- `run_checks.py` を正式な規模で、全スクリプトを単独で流す。
- ランク特能・変化球・査定・戦力・背番号で「悪化」が出るのは想定内。悪化の一覧を全部確認し、**動いてよい項目／いけない項目**に分けて報告する。動いてよい項目だけ `--update-snapshot --only ... --reason` で更新する。値が動いたスクリプトは漏れなく更新し、最後に悪化0・改善0を確かめる。
- 動いてはいけない項目（投手の球速・コントロール・スタミナ・特能、野手、外国人・ドラフト候補）が動いた場合は、更新せずに報告して相談する。
- 特に確認する既存の判定:
  - `check_age_profile.py` のランク点の年齢帯（要注意のランク点の年齢帯を含む）。
  - `check_pitcher_control.py` の総変化量の判定（PR #112。救援の総変化量・良し悪しとの結びつき）。
  - `check_fictional_balance.py` の変化球の判定（変化球数・総変化量の分布、決め球、第二球種）とランク特能の分布。
  - `validate_team_mode.py` の戦力レベル、散らばり、投手王国の目安、背番号。
- 「固定」の基準値を更新する場合は `--update-baselines --only` で項目を絞り、理由を付ける。

### 2-3. 変わらないことの確認
- 助っ人外国人用・ドラフト候補用の投手と野手、架空球団用の野手: seed 1〜1000 で完全に一致。
- 架空球団用の投手: 名前・年齢・役割・投打・球速・コントロール・スタミナ・特能が改修前と一致する（特能は変化球・ランク特能から決まるものがあれば一覧に）。変わった項目を人数つきで一覧にする（ランク特能、救援の変化球、査定など）。
- 先発の変化球は改修前と一致すること（救援だけ変わる）。
- `tests/test_hash_independence.py` が通ること。全テストを流し切り、成功・失敗の件数を報告する（失敗0件にしてから報告する）。
