# 投手の仕上げ（先発のスタミナ・総変化量） 改修指示

## 目的

架空球団用の日本人投手について、次の2つを実在に合わせる。どちらも最後の補正 `apply_fictional_pitcher_balance` の中で直す。

1. **先発のスタミナ**: 平均が高い（特に左投手）。左右差がない。幅が狭い。
2. **総変化量**: 投手の良し悪しとの結びつきが弱い。下位の投手の変化量が多すぎ、上位の投手が少なすぎる。救援が少し多い。

球速・コントロール・救援のスタミナ・変化球の種類と数は変えない。外国人・ドラフト候補用・野手は変えない。

**前提**: ドラフト野手の再現性の修正（`claude/hash-independence`）をマージした後の main で作業する。

## 0. 調査の結果

球団生成600球団（`validate_team_mode.py` と同じ seed）の日本人投手と、実在（2024〜2026年版の日本人）を比べた。

### 0-1. 先発のスタミナ

| 先発のスタミナ | 生成 | 実在 |
|---|---|---|
| 右 平均／標準偏差 | 58.84／9.84 | 57.42／11.61 |
| 左 平均／標準偏差 | 58.32／9.83 | 55.03／9.81 |
| 左右差（左−右） | −0.5 | −2.4 |
| 5%／25%／中央／75%／95% | 42／52／59／65／75 | 40／48／56／63／77 |
| スタミナ×査定の相関 | 0.769 | 0.854 |
| コントロール×スタミナの相関 | 0.525 | 0.511 |

- 平均が高く（右+1.4、左+3.3）、幅が狭い（真ん中に寄りすぎ、上下の端が短い）。
- コントロールとの相関は合っているので、変えない。

### 0-2. 総変化量（変化球の変化量の合計。ストレート系第二球種は数えない）

|---|---|---|

| 先発: 総変化量×コントロールの相関 | 0.215 | 0.461 |

- 変化球の数の分布は合っている（先発で2球種37%・3球種61%、実在31%・66%）。今回は変えない。

## 1. 改修の内容

### 1-1. 先発のスタミナ（22歳以上）
- 先発（`position` が「先発」）で22歳以上の投手に、スタミナの計算の最後で次の変換をかける。
  ```
  stamina = S0 + SA × (stamina − S0) + SD[投げ手]
  ```
  - `SA` は幅を広げる倍率（1より大きい）、`SD` は投げ手ごとの平均のずらし。
- 21歳以下は対象外にする（前回の救援と同じ。若手の補正は先発と救援で共通の定数なので、若手の範囲の判定を崩さないため）。
- 定数は1か所にまとめる（例: `FICTIONAL_STARTER_STAMINA_TRANSFORM`）。

### 1-2. 総変化量と投手の良し悪しの結びつき
- `fictional_pitcher_breaking_balls` の後、`fictional_young_breaking_balls` の前に、総変化量を投手の良し悪しに合わせて増減する処理を入れる。
- 良し悪しの指標 `q`（最終的なコントロール・スタミナを使う）:
  - 先発: `q = ((コントロール − 55) / 13 + (スタミナ − 57) / 11) / 2`
  - 救援: `q = (コントロール − 48) / 10`
- 増減する段階: `delta = round(B[役割] × q + O[役割] + u)`。`u` は −0.5〜0.5 の一様乱数。`delta` は −3〜+3 に収める。
  - `u` は**新しい名前空間の副乱数**（例: `make_sub_rng(seed, "fictional_pitcher_movement_v1")`）から引く。今の副乱数（`fictional_pitcher_balance_v1`）の消費順を変えないため。
- 増やすときは、変化量が小さい球から1段ずつ、その球種の上限（`BREAKING_BY_NAME[...]["max_movement"]`）まで。減らすときは、変化量が大きい球から1段ずつ、下限（`min_movement`）まで。ストレート系第二球種は対象にしない。最後に `enforce_second_pitch_movement_order` をかける。
- 変化球の種類・数・方向は変えない。
- 19歳以下の上限（`fictional_young_breaking_balls`）は、これまでどおり後からかける。

### 1-3. 試作した結果（出発点）

container の作業コピーで試作した（球団生成300球団、`PYTHONHASHSEED=0`）。**この値を出発点にして、2章の判定で微調整する**。

```
先発のスタミナ: S0 = 57, SA = 1.18, SD = {右: −2.0, 左: −4.4}
総変化量:       B = {先発: 0.9, 救援: 0.35}, O = {先発: −0.15, 救援: −0.2}
```

| 項目 | 改修前 | 試作 | 実在 |
|---|---|---|---|
| 先発のスタミナ 右 平均／標準偏差 | 58.84／9.84 | 57.58／11.37 | 57.42／11.61 |
| 先発のスタミナ 左 平均／標準偏差 | 58.32／9.83 | 55.28／10.53 | 55.03／9.81 |
| 先発のスタミナ 5%／25%／中央／75%／95% | 42／52／59／65／75 | 39／49／56／64／75 | 40／48／56／63／77 |
| コントロール×スタミナの相関 先発／全体 | 0.525／0.57前後 | 0.514／0.486 | 0.511／0.491 |
| 総変化量 先発 平均 | 6.60 | 6.47 | 6.50 |
| 総変化量 救援 平均 | 6.61 | 6.49 | 6.27 |
| 総変化量 査定 下位⅓／中位／上位⅓ | 5.88／6.67／7.20 | 5.30／6.55／7.49 | 5.34／6.24／7.49 |
| 先発: 総変化量×コントロール／×スタミナ | 0.215／0.223 | 0.503／0.494 | 0.461／0.615 |
| 救援: 総変化量×コントロール | 0.169 | 0.350 | 0.310 |
| 球団の投手力（上位13人）中央／標準偏差 | 345.5／12.83 | 346.8／14.55 | 345.1／13.15 |

試作で残った課題（正式版で直す）:
- 救援の総変化量の平均が +0.2 多い（6.49、実在6.27）。`O[救援]` を −0.45 前後にする。
- 総変化量の標準偏差が少し大きい（先発1.79、実在1.63）。`B[先発]` を少し下げるか、`u` の幅を狭める。
- 球団の投手力の散らばりが少し広がる（標準偏差 12.8 → 14.6、実在13.2）。PR #108 の散らばりの判定（SD比0.85〜1.20）に入るか確認する。

## 2. 判定

### 2-1. 新しい判定（`scripts/check_pitcher_control.py` に節を追加、球団生成300球団）

| 項目 | 合格の範囲 |
|---|---|
| 先発のスタミナの平均（右・左） | 実在±0.8 |
| 先発のスタミナの左右差 | −2.4±1.0 |
| 先発のスタミナの標準偏差（右・左） | 実在±1.2 |
| 先発のスタミナの 10%・中央・90% | 実在±2 |
| 総変化量の平均（先発・救援） | 実在±0.2 |
| 総変化量の標準偏差（先発・救援） | 実在±0.2 |
| 総変化量 査定の下位⅓・上位⅓の平均 | 実在±0.3 |
| 総変化量×コントロールの相関（先発・救援） | 実在±0.10 |
| 総変化量×スタミナの相関（先発） | 0.45以上（実在0.615） |

- これらは「実在」の判定として、PR #110 の仕組み（誤差つきの合否、id）で作る。
- 個別生成（架空球団用・投手5000人）は参考として同じ表を出す。

### 2-2. 既存の判定の扱い
- 先発のスタミナの「固定」の2項目（`check_baselines.json` の先発のスタミナ）は、意図して変えるので、今回の新しい判定に置き換えるか、`--update-baselines --reason` で更新する。どちらにしたかを報告する。
- `run_checks.py` を正式な規模で流す。
  - 先発のスタミナ・総変化量・それに伴う査定の変化で「悪化」が出るのは想定内。悪化の一覧を全部確認し、**今回の変更で動いてよい項目かどうか**を一つずつ分けて報告する。
  - 動いてよい項目だけ `--update-snapshot --reason` でスナップショットを更新する。
  - 動いてはいけない項目（野手・外国人・ドラフト候補・救援のスタミナなど）が悪化した場合は、更新せずに報告して相談する。
- 特に確認する既存の判定:
  - `check_fictional_balance.py` の変化球の判定（総変化量の分布、決め球の変化量、第二球種の順序など）。
  - `check_age_profile.py` の若手の判定（19歳以下の変化量の上限、若手のスタミナ）。
  - `validate_team_mode.py` の戦力レベル (a)〜(f)、球団ごとの散らばり（投手力・投手の査定の平均）、投手王国の目安、背番号。

### 2-3. 変わらないことの確認
- 助っ人外国人用・ドラフト候補用の投手と野手、架空球団用の野手: seed 1〜1000 で完全に一致。
- 架空球団用の投手: 名前・年齢・役割・投打・球速・コントロール・救援のスタミナ・変化球の種類と数・方向が改修前と一致する。変わった項目を人数つきで一覧にする（先発のスタミナ、変化量、それに続く特能・ランク特能など）。
- テストの期待値は、架空球団用の投手と球団生成の分だけ、理由を書いて更新してよい。
- `tests/test_hash_independence.py` が通ること。
