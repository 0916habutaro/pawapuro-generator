# 投手の球速の形 改修指示

## 目的

架空球団用の日本人投手の**球速の分布の形**を実在に合わせる。平均・標準偏差・10%／中央／90%の点は今も合っているが、1km刻みで見ると形がでこぼこしている。

- 先発右: 148kmに谷（生成5.3%、実在9.4%）、151kmに山。154〜157kmが多い。
- 救援右: 151〜153kmが少なく（21.9%、36.1%）、145〜147kmと154〜159kmが多い。
- 先発左: 148〜150kmが少なく（30.4%、43.9%）、145〜147kmと151〜153kmが多い。
- 実在は真ん中に集まり、裾が長い形。生成は真ん中が平らで、継ぎ目に谷と山がある。

原因: 球速は、元の生成の値（整数に近い値に固まっている）に、役割のずらし・裾の縮め（`shape_speed` の148・155）・投げ手のずらし・投げ手ごとの裾（`FICTIONAL_PITCHER_HAND_SPEED_TAILS`。先発右は148で下側を1.6倍に伸ばす）を順にかけている。縮めたところと伸ばしたところの継ぎ目で、四捨五入した値に谷と山ができる。

**直し方**: 今の処理はそのまま残し、最後（四捨五入の前）に、役割×投げ手ごとに**順位を保ったまま実在の分布へ写す**（分位の対応表）。順位は変えないので、球速とコントロール・スタミナなどの結びつきはほぼそのまま残る。

**対象**: 架空球団用の日本人投手の22歳以上（`apply_fictional_pitcher_balance`）。21歳以下（若手の補正）、ドラフト候補用、助っ人外国人用は変えない。

**前提**: PR #135 をマージした後の main（5477d4a）で作業する。

## 1. 改修の内容

### 1-1. 四捨五入の前に分位で写す
`apply_fictional_pitcher_balance` の、投げ手ごとの裾（`FICTIONAL_PITCHER_HAND_SPEED_TAILS`）をかけたあと、`speed = round(speed)` の直前に入れる。**22歳以上（`age > FICTIONAL_YOUNG_MAX_AGE`）だけ**にかける。

```
u = make_sub_rng(seed, "fictional_pitcher_speed_shape_v1").random() − 0.5
x = speed + u                       # 固まった値をならす（同じ値の投手が同じ値に写らないように）
表 = 試作表[役割|投げ手]            # 役割は先発／救援（hand_key と同じ）
if x <= from[0]:  speed = to[0] + (x − from[0])
elif x >= from[-1]: speed = to[-1] + (x − from[-1])
else: speed = from と to の折れ線で x を写した値
speed = round(speed)                # 今と同じ
```
- 乱数は新しい副乱数だけを1回使う。共通の乱数（`rng`）は進めない。
- コントロール・スタミナの連動に使う球速（`linked_speed`）はこれより前に決まっているので変わらない。
- 21歳以下は今と同じ（若手の補正は、写す前の値をもとに今までどおり計算する）。
- 肩力（`speed − 81 + …`）、救援の球種数（#119）、変化球の種類（#133）、総変化量（#134）、ノビの連動などは、写したあとの球速を使う（今と同じ順番）。

### 1-2. 表（`data/config/fictional_pitcher_speed_shape.json`、新規）
試作表 `docs/投手の球速の形_試作表.json` をそのまま置く。役割×投げ手（先発|右、先発|左、救援|右、救援|左）ごとに、分位 p（0.002、0.005、0.01〜0.99 を0.01刻み、0.995、0.998 の103点）での `from`・`to` を持つ。

- `from`: 写す前の球速（四捨五入の前の値に −0.5〜0.5 の一様乱数を足したもの）の分位。22歳以上の生成（球団生成300球団）から作った。
- `to`: 実在（2024〜2026年版の日本人投手で、22歳以上か年齢が分からない投手）の球速の分位。各値を整数の幅（±0.5）に広げ、標準偏差1.0の正規分布で均した分布から作った。均すのは、実在の人数（1区分127〜399人）の揺れを写さないため。
- **表を作るスクリプト** `scripts/pitcher_speed_shape.py --build` を作る。写さない状態で球団生成（seed 1〜300）を流して四捨五入前の値を集め、上のとおりに `from`・`to` を作る。`from` は生成から作るので、**球速より前の処理を変えたら作り直す**ことを README とスクリプトの説明に書く。作り直した表と試作表の差を報告する（各点で0.3km以内なら試作表のままでよい）。

## 2. 判定

### 2-1. 新しい判定（`check_pitcher_control.py`、球団生成300球団）
役割×投げ手の4区分ごと。実在の誤差は異なる選手の数で出す。

| 項目 | 合格の範囲 |
|---|---|
| 3km刻みの割合（145〜147、148〜150、151〜153、154〜156） | 実在±（誤差の2倍。ただし最低±4ポイント） |
| 1km刻みの全変動距離 | 実在の揺れ（半分に分けて比べる方法で見積もった値）以下 |
| 先発右の148kmの割合 | 7%以上 |

実在の揺れの見積もり: 異なる選手を無作為に半分ずつに分け（200回）、2つの半分どうしの全変動距離の中央値を2で割った値。乱数の種を固定して、`--build-real` で実在の値と一緒に書き出す。

### 2-2. 既存の判定の扱い
- 球速の左右・役割の判定（平均±0.5、標準偏差、10%／中央／90%、145以下、162以上、左投手の155以上）は**合格のまま**であること。162以上（0.5%以下）は余裕が小さいので値を必ず書く。
- 動いてよい項目: 球速と、球速を使うもの（肩力、救援の球種数・変化球の種類・総変化量、奪三振など球速の帯で付ける特能、ノビのランク、査定とそれを使う判定）。#133・#134 の判定は合格のままであること。
- 動いてはいけない項目: 21歳以下の投手（球速を含む全項目）、コントロール・スタミナ（`linked_speed` を使うので変わらないはず）、野手、外国人、ドラフト候補。動いた場合は、更新せずに報告して相談する。
- 見張りの項目: 日本人投手の査定値の標準偏差（#135 で受け入れ、60.427）。値を報告する。
- 判定の範囲は実在から決めたまま動かさない。

### 2-3. 変わらないことの確認
- 架空球団用の日本人投手: 21歳以下は全項目一致。22歳以上は、球速と、球速から決まる項目（肩力、変化球、特能、ランク特能、査定）のほかは一致。コントロール・スタミナは全員一致。
- 野手・外国人・ドラフト候補: 全項目一致（背番号を除く）。
- 変わった項目を人数つきで一覧にする。
- `tests/test_hash_independence.py` が通ること。全テストを流し切り、成功・失敗の件数を報告する（失敗0件にしてから報告する）。

### 2-4. 進め方
- 調整中は `check_pitcher_control.py`・`check_fictional_balance.py`・`check_pitcher_rank_pitches.py` だけを流す（`--quick` でも可）。
- 正式な流しは PC で1回（並列数2）。外国人・ドラフト候補は、全員一致を確かめたら流さなくてよい。
