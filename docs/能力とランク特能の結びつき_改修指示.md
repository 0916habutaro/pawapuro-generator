# 能力とランク特能の結びつき（架空球団用） 改修指示

## 目的

架空球団用の日本人のランク特能のうち、**回復・打たれ強さ（投手）、回復・送球・キャッチャー（野手）**を、能力の高い選手ほど良いランクになるように結びつける。

- ランクの割合（PR #127）と年齢の傾き（PR #128）は実在に合った。ただ、**どの選手が良いランクを持つか**が能力とほとんど関係なく決まっている。
- 実在は、たとえば先発の回復とコントロール・スタミナの相関が 0.70、捕手のキャッチャーと捕球・守備力の相関が 0.73 と強い。生成は 0.04〜0.14。
- 野手の送球は、生成では肩力だけに結びつけている（PR #124）。ところが実在の送球は、肩力とはほぼ無関係（相関 0.05）で、捕球・守備力と結びついている（0.50・0.44）。

この PR は3段階の1本目。2本目で特能（パワー・肩力・総変化量などとの結びつき）を、そのあと助っ人外国人用・ドラフト候補用に同じ仕組みを入れる。今回は**架空球団用の日本人だけ**を対象にする。外国人・ドラフト候補用、能力・特能は変えない。

**前提**: PR #128 をマージした後の main（cdf0b2d）で作業する。

## 1. 改修の内容

### 1-1. 能力によるランクの傾き
`fictional_ranked_specials` に引数 `ability_tilt`（ランク特能の名前 → 傾き t を返す関数）を足す。t が0でなければ、年齢の傾き（`fictional_age_rank_weights`）のあとで、各ランクの重みに `exp(t × s)` を掛ける。s はランクの点（A=3、B=2、C=1、D=0、E=−1、F=−2、G=−3）。
- 年齢の傾きと同じく、**A・G の重みは増やさない**（倍率の上限 1）。
- 重みを変えるだけで、乱数を引く回数は変えない。

傾き t = κ × z。z は能力の合成値:
```
z = 平均( (能力 − 実在の平均) ÷ 実在のSD )
```

| ランク特能 | 対象 | 能力 | 実在の平均・SD | κ |
|---|---|---|---|---|
| 回復 | 先発 | コントロール・スタミナ | コントロール 55.27・13.27、スタミナ 56.55・11.04 | 1.3 |
| 回復 | 救援 | コントロール・スタミナ | コントロール 48.16・10.33、スタミナ 46.96・5.84 | 0.6 |
| 打たれ強さ | 先発 | 同上（先発） | 同上 | 0.5 |
| 打たれ強さ | 救援 | 同上（救援） | 同上 | 0.3 |
| 回復 | 野手 | ミート・守備力・捕球 | ミート 42.11・10.71、守備力 51.96・11.70、捕球 48.58・11.15 | 1.1 |
| 送球 | 野手 | 捕球・守備力 | 同上（野手全体） | 0.75 |
| キャッチャー | メインが捕手 | 捕球・守備力 | 捕球 46.47・10.25、守備力 49.14・9.34（捕手） | 1.7 |

- 平均・SDは実在（2024〜2026年版の日本人、投手は先発・救援ごと、捕手は捕手だけ）から出した値。定数として持つ。
- 能力は、`apply_fictional_pitcher_balance`・`apply_fictional_fielder_balance` でランク特能を引く時点の値（投手は `control`・`stamina`、野手は `values`）を使う。
- サブポジが捕手の野手のキャッチャーには傾きをかけない。

### 1-2. 重みを直す
傾きをかけると、能力の高い・低い選手が端のランクに寄るので、全体のランクの割合が広がる。全体の割合が今と同じ（実在どおり）になるように、次の重みを変える（A／B／C／D／E／F／G）。
```
FICTIONAL_PITCHER_RANKED_WEIGHTS
  回復_先発          0.25／1.1／9.0／43.8／38.3／7.1／0.42   （今 0.3／5.5／13.7／33.3／35／11.8／0.5）
  回復_救援          0.28／5.0／23.1／44.6／24.8／1.7／0.47  （今 0.3／9／23.8／39.5／24.5／3.2／0.5）
  打たれ強さ         0.38／4.0／21.1／63.2／10.0／1.0／0.19  （今 0.4／7／22.6／55／12／2.8／0.2）
FICTIONAL_FIELDER_RANKED_WEIGHTS
  回復               0.18／0.6／5.6／26.7／62.0／4.7／0.26   （今 0.2／2.5／10.3／24／52／10.7／0.3）
  送球               0.38／3.2／19.5／44.2／28.9／3.7／0.19  （今 0.4／5.5／20／37／30／6.9／0.2）
  キャッチャー_捕手  0.09／0.05／3.2／60.5／29.9／6.2／0.09  （今 0.1／0.9／6.0／38.4／25.7／12.9／0.1）
```
丸める前の値は `docs/能力とランク特能の結びつき_試作表.json` の `weights`。

### 1-3. 年齢の傾きを弱める
能力は年齢とともに上がるので、能力で傾けると、そのぶん年齢によるランクの差も大きくなる（試作で、年齢との相関が 0.23→0.29、野手の30〜33歳のランク点が 2.08→2.93）。その分、年齢の傾き（PR #128 の β）を弱める。γ（幅）は変えない。
```
FICTIONAL_AGE_RANK_BETA
  野手  今: (20,−0.18) (23.5,−0.035) (27.5,0.012) (31.5,0.055) (36,0.03)
        新: (20,−0.145) (23.5,−0.028) (27.5,0.006) (31.5,0.04) (36,0.015)
  投手  今: (20,−0.12) (23.5,−0.06) (27.5,0.025) (31.5,0.035) (36,0.04)
        新: (20,−0.095) (23.5,−0.048) (27.5,0.018) (31.5,0.025) (36,0.028)
```

### 1-4. 送球の肩力との結びつきを弱める
送球を捕球・守備力に結びつけると、肩力80以上の選手の送球が上がりすぎる（試作 1.03、実在 0.55）。肩力が高い選手は守備力も高めのため。`FICTIONAL_FIELDER_RANK_LINK_RATES["送球"]` の上げる確率を **0.4 → 0.2** にする（下げる確率 0 はそのまま。条件はそのままで確率だけ変えるので、乱数を引く回数は変わらない）。

## 2. 判定

### 2-1. 新しい判定（球団生成300球団、架空球団用の日本人）
PR #110 の仕組み（「実在」の判定、誤差つきの合否、id）で作り、`run_checks.py` に組み込む。投手は `scripts/check_pitcher_rank_pitches.py`、野手は `scripts/check_fielder_position.py` に節を足す。

| 項目 | 合格の範囲 |
|---|---|
| 0-1 の7区分の、能力の合成値との相関 | 実在±0.12（誤差つき。誤差は異なる選手の数で出す） |
| 0-1 の7区分のランクの割合（B〜F） | 各ランク 実在±4ポイント（誤差つき） |

- 個別生成（架空球団用・投手5000人・野手5000人）は参考として同じ表を出す。

### 2-2. 検証の進め方（PC の負荷を減らす）
- **PC で作業する**（外国人の名前のデータベースがクラウドにないため、球団生成の値が PC と合わない）。
- 調整中は、節を足した2本と `check_age_profile.py` だけを流す（`--quick` でも可）。
- 値が決まったら、変えていない区分（ドラフト候補用・助っ人外国人用の投手と野手）が seed 1〜1000 で改修前と完全に一致することを確かめる。一致したら `check_draft_balance.py`・`check_foreign_balance.py` は流さず、スナップショットもそのままにする。
- 架空球団用の投手・野手と球団生成を使う判定は、正式な規模で1回流す。スナップショットは流し終えた結果から書き込む（PR #125〜#128 と同じやり方）。更新した後の確認は、更新した項目の値がスナップショットと一致することで済ませる。
- 並列数は2程度に下げる。

### 2-3. 既存の判定の扱い
- ランク特能・査定・戦力・背番号で値が動くのは想定内。悪化の一覧を全部確認し、**動いてよい項目／いけない項目**に分けて報告する。動いてよい項目だけスナップショットを更新する。
- 動いてはいけない項目（能力・特能、外国人、ドラフト候補）が動いた場合は、更新せずに報告して相談する。
- 特に確認する既存の判定: `check_age_profile.py` のランク点の年齢帯・年齢との相関・SD・B以上の数（PR #128）、`check_fielder_speed.py` の送球のランク点（肩力の帯ごと、PR #124）、PR #127 のランクの割合（11区分）、`check_fielder_position.py` のポジションごとの査定、`validate_team_mode.py` の戦力・散らばり・背番号。
- 判定の範囲は実在から決めたまま動かさない。合格にならない項目があれば、値と範囲を報告する。

### 2-4. 変わらないことの確認
- 架空球団用の投手・野手: 名前・年齢・ポジション・投打・能力・弾道・特能・変化球・身長・体重が改修前と一致する。変わった項目（ランク特能、査定、背番号）を人数つきで一覧にする。
- `tests/test_hash_independence.py` が通ること。全テストを流し切り、成功・失敗の件数を報告する（失敗0件にしてから報告する）。
