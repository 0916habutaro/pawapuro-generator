# 投手の特能と球速 改修指示（表の値だけを変える小さい改修）

## 目的

架空球団用の日本人投手で、6つの特能（キレ○・逃げ球・負け運・力配分・要所○・ポーカーフェイス）を**球速の遅い投手が持ちすぎている**。実在は球速と無関係か、速い投手がやや多く持つ。

**app.py は変えない。** `data/config/fictional_ability_special_link.json` の6特能の値（w・b と、区分ごとの rho・zsd・qsd・M）を書き換えるだけにする。検証も、変わる区分に関わる判定だけを流す。

**前提**: PR #136 をマージした後の main（f22e2fc）で作業する。

---

## 0. 原因

#130 の付け替え（`fictional_ability_special_link`）は、特能ごとの能力の合成値 z から「能力の総合」（球速・コントロール・スタミナ・総変化量の平均）の分を 0.75 の割合で除いてから傾ける。6特能は合成値の重み w に球速が入っていない（入っていても小さい）ため、総合を除いた分だけ**球速に負の向き**が残り、持つ人が遅い投手に偏っている。

特能を持つ人と持たない人の能力の差（実在のSD単位、球団生成300球団）:

| 特能 | 球速 実在／生成 | z |
|---|---|---|
| キレ○ | +0.23／−0.73 | −7.1 |
| 逃げ球 | +0.17／−0.38 | −4.6 |
| 負け運 | −0.01／−1.10 | −4.1 |
| 力配分 | +0.29／−0.63 | −3.9 |
| 要所○ | +0.53／−0.36 | −3.6 |
| ポーカーフェイス | −0.20／−0.95 | −3.4 |

## 1. 改修の内容

### 1-1. 表の値を書き換える
`data/config/fictional_ability_special_link.json` の 区分「架空球団用_日本人」→「特能」→「投手」の6特能について、試作表 `docs/投手の特能と球速_試作表.json` の値で次を置き換える。

- `w`（重み。球速を足し、ほかの重みも合わせ直した）と `b`
- 「区分」の先発・救援それぞれの `rho`・`zsd`・`qsd`・`M`

`p`・`gain`・ほかの特能・ほかの区分（助っ人外国人用・ドラフト候補用）・野手は変えない。

| 特能 | w（球速・コントロール・スタミナ・変化球数・総変化量） | b（今→新） |
|---|---|---|
| キレ○ | 0.50・0.48・0.55・—・0.64 | 1.2→1.97 |
| 逃げ球 | 0.34・0.39・0.45・—・0.40 | 0.5→1.87 |
| 負け運 | 0.74・0.97・0.54・—・0.62 | 1.4→1.82 |
| 力配分 | 0.58・0.62・0.24・0.10・0.36 | 0.75→1.59 |
| 要所○ | 1.02・0.89・1.06・—・0.77 | 2.6→2.92 |
| ポーカーフェイス | 0.55・0.95・0.48・0.27・0.44 | 1.0→1.36 |

決め方: 球団生成の日本人投手の能力から、特能を持つ確率（p × r）で重みづけした「持つ人と持たない人の差」を見積もり、5つの能力の差が実在に近づくように w・b を選んだ（実在の差は `special_ability_link_real.json` の値）。

### 1-2. rho・zsd・qsd・M を測り直す
試作表の rho・zsd・qsd・M は、クラウドの球団生成（main f22e2fc、seed 1〜300）で測った値。**PC で同じ測り方で測り直して使う**（#130 で使った測り方。新しい w・b で、先発・救援ごとに z と能力の総合の相関・SD、exp(b × z') の平均）。試作表との差を報告する。

## 2. 試作の結果（クラウドの球団生成300球団）

| 特能 | 球速の差 実在／改修前／試作 | 保有率 改修前／試作／実在 |
|---|---|---|
| キレ○ | +0.23／−0.73／+0.14 | 13.2／13.7／14.1% |
| 逃げ球 | +0.17／−0.38／−0.03 | 22.0／21.6／18.8% |
| 負け運 | −0.01／−1.10／+0.15 | 4.8／5.3／3.3% |
| 力配分 | +0.29／−0.63／+0.33 | 5.1／4.7／4.3% |
| 要所○ | +0.53／−0.36／+0.61 | 3.9／4.5／3.7% |
| ポーカーフェイス | −0.20／−0.95／−0.33 | 6.2／5.6／4.7% |

- 6特能の球速の差の z は −7.1〜−3.4 → −1.7〜+0.6。
- 能力との結びつきのずれ0.4以上: 26組→20組、|z|>3: 16組→9組。
- ほかの能力との差もほぼ保たれた（キレ○×総変化量 0.96→1.01（実在1.19）、キレ○×スタミナ 0.43→0.65（0.64）など）。逃げ球×コントロールは 0.92→0.98（実在0.52）で残る（元の付き方による。今回は扱わない）。
- 投手の青特 2.859→2.857、赤特 0.973→0.978、緑特 0.364→0.364、査定 284.53→284.52。

## 3. 判定と検証（時間を短くする）

### 3-1. 流す判定
変わるのは**架空球団用の日本人投手の特能（と査定）だけ**。次だけを正式な規模で流す（並列数2、1回）:
- `check_special_profile`（#130 の付け替えの判定）
- `check_fictional_balance`
- `validate_team_mode`
- `check_age_profile`

野手・外国人・ドラフト候補・球速・変化球・ランク特能に関わるもの（`check_fielder_*`・`check_pitcher_control`・`check_pitcher_rank_pitches`・`check_foreign_balance`・`check_draft_balance`）は、**流す代わりに**「投手の特能と査定のほかは全員一致」を確かめる（2-3）。一致すれば流さなくてよい。

### 3-2. 合否
- #130 の判定（6特能の差・保有率）が合格のままか、改善すること。6特能の**球速**の差が実在±0.4（誤差つき）に入ること（新しい判定を `check_special_profile` に足す。ほかの5能力は今の判定のまま）。
- #130 の歯止め「投手 保有率（改修前±1.0）」: 試作では要所○ +0.5、負け運 +0.5 で範囲内。外れたら、`gain` を下げて合わせてよい（理由を書く）。
- 判定の範囲は実在から決めたまま動かさない。スナップショットは、流した判定の動いた項目だけを流し終えた結果から書き込む。

### 3-3. 変わらないことの確認
- 架空球団用の日本人投手: 特能と査定（とそれを使う背番号などの球団の値）のほかは全員一致。
- 野手・外国人・ドラフト候補: 全員一致（背番号を除く）。
- 全テストを流し、成功・失敗の件数を報告する（失敗0件にしてから報告する）。
