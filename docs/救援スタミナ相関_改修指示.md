# コントロールとスタミナの相関（救援投手のスタミナ） 改修指示

## 目的

架空球団用の日本人投手で、**コントロールとスタミナの相関が実在より高い**件を直す。

調べると、ずれているのは**救援投手だけ**だった。先発はほぼ実在どおり。救援は、実在では「コントロールが良い救援ほどスタミナもある」という関係がかなり弱いのに、生成では先発と同じくらい強く出ている。あわせて、救援のスタミナの幅も実在より広い。

今回は**救援投手のスタミナだけ**を直す。コントロール・球速・先発は変えない。個別生成と球団生成の両方に効く。

**前提**: PR #108（球団ごとの散らばり）をマージした後の main で作業する。

---

## 0. 調査の結果（PR #108 のブランチ、85382b1）

球団生成300球団（seed 1〜300）の日本人投手と、実在（2024〜2026年版の日本人）を比べた。

### 0-1. 相関（コントロール×スタミナ）

| 区分 | 生成 | 実在 | 実在の人数 |
|---|---|---|---|
| 全体 | 0.570 | 0.491 | 1,126 |
| 先発 | 0.527 | 0.511 | 573 |
| 先発・右／左 | 0.525／0.532 | 0.471／0.636 | 365／208 |
| **救援** | **0.509** | **0.216** | 553 |
| 救援・右／左 | 0.508／0.515 | 0.184／0.297 | 416／137 |

- 個別生成（架空球団用・投手4000人）でも同じ。全体0.558、先発0.514、救援0.505。
- 全体の相関が高いのは、ほぼ救援の分。

### 0-2. 救援のスタミナ

| 救援のスタミナ | 生成 | 実在 |
|---|---|---|
| 平均 | 47.96 | 46.96 |
| 標準偏差 | 7.99 | 5.84 |
| 5%／10%／25%／中央／75%／90%／95% | 35／38／42／48／53／58／62 | 38／39／43／47／51／54／58 |
| スタミナ×査定の相関 | 0.629 | 0.424 |
| 球団ごとの平均の標準偏差 | 1.81 | 1.83 |

- 生成は救援のスタミナの幅が広く、選手の良し悪し（査定）とも強く結びついている。実在の救援は、スタミナがあまり散らばらず、選手の良し悪しとの結びつきも弱い。
- 先発のスタミナは、平均58.8（実在56.6）、標準偏差9.9（実在11.0）。少しずれているが、今回は直さない（5章）。

### 0-3. 原因
- 選手格が上の投手ほど、コントロールもスタミナも高い（先発の例: スター級 66.1／69.1、二軍級 43.4／50.3）。救援にも同じ仕組みがかかっている。
- 最後の補正 `apply_fictional_pitcher_balance` でも、コントロールが高いほどスタミナを上げている（`FICTIONAL_STAMINA_PER_CONTROL = 0.12`）。
- 実在の救援は、スタミナを使う場面が少ないぶん、制球の良し悪しとスタミナがあまり結びつかないとみられる。

## 2. 改修の内容（`apply_fictional_pitcher_balance` の中だけ）

### 2-1. 救援のスタミナの変換
- 救援投手（`position` が「中継ぎ」「抑え」）だけ、今のスタミナの計算（役割のずらし、コントロール・球速との連動）が終わった後に、次の変換をかける。
  ```
  stamina = S0 + A × (stamina − S0) − B × (control − C0) + D
  ```
  - `A`: 幅を縮める倍率
  - `B`: コントロールとの結びつきを弱める係数（最終的なコントロールを使う）
  - `D`: 平均のずらし
- 位置は、21歳以下の補正（`fictional_young_transform`）の**前**。若手の補正はそのまま後からかける。
- 先発には何もしない。
- 定数は1か所にまとめる（例: `FICTIONAL_RELIEVER_STAMINA_TRANSFORM`）。

### 2-2. 乱数
- 新しい乱数は使わない。
- スタミナで決まる特能（もしあれば）の付け直しで乱数の引く回数が変わり、後の抽選がずれるのは、前々回・前回と同じく受け入れる。変わった項目を一覧で報告する。

### 2-3. 試作した結果（出発点）

container の作業コピーで試作した（球団生成200球団、個別生成4000人）。**この値を出発点にして、3章の判定で微調整する**。

```
S0 = 48, A = 0.75, B = 0.18, C0 = 48, D = −0.8
```

| 項目 | 改修前 | 試作 | 実在 |
|---|---|---|---|
| 相関 全体（球団生成） | 0.570 | 0.496 | 0.491 |
| 相関 先発 | 0.527 | 0.529（変わらない） | 0.511 |
| 相関 救援 | 0.509 | 0.227 | 0.216 |
| 相関 救援・右／左 | 0.508／0.515 | 0.229／0.226 | 0.184／0.297 |
| 救援のスタミナ 平均／標準偏差 | 47.96／7.99 | 47.02／5.47 | 46.96／5.84 |
| 救援のスタミナ 5%〜95% | 35／38／42／48／53／58／62 | 39／40／44／47／50／55／57 | 38／39／43／47／51／54／58 |
| スタミナ×査定の相関（救援） | 0.629 | 0.448 | 0.424 |
| 球団の投手の査定の平均 中央／90% | 292.7／305.5 | 291.9／302.6 | 287.7／297.2 |
| 球団ごとの救援のスタミナの平均の標準偏差 | 1.81 | 1.32 | 1.83 |
| 個別生成 相関 全体／救援 | 0.558／0.505 | 0.481／0.225 | — |

- 試作では、救援の標準偏差が5.47で少し狭い（実在5.84）。`A` を0.8前後に上げてよい。
- 救援・左の相関（実在0.297）は、実在の人数が137人で誤差が大きい。右と左で係数を分けなくてよい。
- 球団の投手の査定の平均の90%が 305.5 → 302.6 に下がり、PR #108 で受け入れた不合格（上限301.45）が小さくなる。

## 3. 判定

### 3-1. 新しい判定（`scripts/check_pitcher_control.py` に「救援のスタミナ」の節を追加。球団生成300球団）

| 項目 | 合格の範囲 |
|---|---|
| コントロール×スタミナの相関（救援） | 0.216±0.08 |
| 同（救援・右、救援・左） | それぞれ実在±0.12 |
| 同（全体） | 0.491±0.05 |
| 救援のスタミナの平均 | 46.96±0.5（右・左それぞれ実在±0.8） |
| 救援のスタミナの標準偏差 | 5.84±0.6 |
| 救援のスタミナの 10%・中央・90% | 実在±2 |
| スタミナ×査定の相関（救援） | 0.424±0.10 |

- 個別生成（架空球団用・投手5000人）は、同じ表を参考として出す。救援の相関が 0.10〜0.35 に入ることだけ確認する。

### 3-2. 既存の判定の扱い
- `check_pitcher_control.py` の「スタミナが改修前±0.3」の救援2項目（基準値 47.83／48.10）は、今回の新しい判定に置き換える。**先発の2項目（58.75／58.70）はそのまま残し、合格すること**（先発は変えないため）。
- `check_fictional_balance.py`（個別生成5000人）: 「コントロール×スタミナ相関 +0.38〜+0.58」を含む全項目。試作では0.481で合格の見込み。
- `validate_team_mode.py`（200球団）: PR #108 の球団ごとの散らばりの判定を含む全項目。
  - 球団ごとの救援のスタミナの平均の標準偏差が、実在の0.7倍まで下がる（試作で1.32、実在1.83）。散らばりの判定は「1.25以下」だけなので合格するが、値を報告する。
  - 投手の査定の平均の90%の値を報告する（PR #108 で上限を+2.75超えていた件）。
- `check_age_profile.py`、全テスト。

### 3-3. 変わらないことの確認
- 先発投手: 個別生成 seed 1〜5000 で、能力・特能すべてが改修前と一致する。
- 助っ人外国人用・ドラフト候補用の投手と野手、架空球団用の野手: seed 1〜1000 で完全に一致（ドラフト候補用の野手は同じ `PYTHONHASHSEED` で比べる）。
- 救援投手: 名前・年齢・役割・投打・球速・コントロール・変化球の種類が一致する。変わった項目を人数つきで一覧にする。
- テストの期待値は、架空球団用の救援投手と球団生成の分だけ、理由を書いて更新してよい。
