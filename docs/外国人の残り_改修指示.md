# 外国人の残り（投手の特能・ランク、野手の走力・年齢・打撃の幅） 改修指示

## 目的

助っ人外国人用の選手で、実在とのずれが残っている次の点を直す。

- **投手**: 赤の「対ランナー×」を出しておらず、代わりに青の「対ランナー」が多い（PR #116 で分かった、実在の読み違いの名残り）。抜け球・回またぎ○・ナチュラルシュートが少ない。ランク特能が良すぎる。
- **野手**: 走力が低い（外野手・遊撃手の速い選手が少ない）。年齢が高い。ミート・パワーの幅が狭く、ミートとパワーの結びつきが弱い。

対象は助っ人外国人用（個別生成と、球団生成の中の外国人）。架空球団用の日本人・ドラフト候補用は変えない。

**前提**: PR #120 をマージした後の main（0619a5d）で作業する。

---

## 0. 調査の結果

球団生成300球団（seed 1〜300、`PYTHONHASHSEED=0`）の外国人（投手1,028人・野手888人）と、実在の外国人を比べた。実在の基準は、日本人と同じく 2024〜2026年版（投手122人・野手102人）。人数が少ないので、2022〜2026年版（野手172人）も並べて見た。実在の「対ランナー」は PR #116 の読み方（赤特）。

### 0-1. 投手

| 項目 | 生成 | 実在 |
|---|---|---|
| 赤特の数 | 0.77 | 1.07 |
| ランク点 | +0.44 | −1.22 |
| 対ランナー×（赤） | 0% | 13.9% |
| 対ランナー（青） | 15.8% | 4.9% |
| 抜け球 | 13.6% | 26.2% |
| 回またぎ○ | 6.9% | 16.4% |
| 逃げ球 | 26.9% | 36.1% |
| ナチュラルシュート | 2.4% | 9.8% |

- 「対ランナー」: 外国人用の特能の候補（`foreign_pitcher_special_abilities`）で、青の対ランナーが 0.15 になっていて、赤の対ランナー×がない。実在の赤の「対ランナー」を青と読んでいた頃の値と考えられる。
- ランク点のずれ（+1.7）は、ノビ +0.7・対左打者 +0.6・打たれ強さ +0.4・対ピンチ +0.3。どれも A・B が実在より多い（例: 打たれ強さ B 9.3%、実在 4.2%。対ピンチ A・B 5.5%、実在 0%）。
- 球速・コントロール・スタミナ・変化球・査定は合っている。

### 0-2. 野手

| 項目 | 生成 | 実在 2024〜26 | 実在 2022〜26 |
|---|---|---|---|
| 走力 | 54.7 | 59.5 | 57.6 |
| 走力 外野手／遊撃手 | 59.1／70.7 | 65.9／76.6 | 63.9／72.8 |
| 走力 75%点／90%点 | 65／73 | 74／80 | 72／79 |
| 年齢 平均（SD） | 30.7（3.5） | 29.1（4.5） | 29.1（4.5） |
| ミートの SD／パワーの SD | 9.3／8.5 | 12.2／11.5 | 11.0／10.3 |
| ミート×パワーの相関 | 0.31 | 0.46（2022〜26） | |
| 査定 平均（SD） | 271.3（36.7） | 273.1（47.1） | 268.0（44.1） |

- 実在の外国人野手の走力は、年版とともに上がっている（2022 53.4 → 2026 61.0）。今の値は 2022〜23 年版に近い。
- 一塁手・三塁手・捕手の走力は合っている。外野手・遊撃手だけ低い。
- 年齢の重み（`FOREIGN_AGE_WEIGHTS["野手"]`）が30歳前後に寄りすぎ。33歳以上は走力が下がる（`speed_mean -= 4.0`）ので、走力が低い一因にもなっている。

## 1. 改修の内容（助っ人外国人用だけ）

### 1-1. 投手の特能
`foreign_pitcher_special_abilities` の候補の確率を変える。
- 青の「対ランナー」: 0.15 → 0.05
- 赤の「対ランナー×」を足す: 0.16（選手格の補正を掛ける。対ランナーとは矛盾の組み合わせで、両方は付かない）
- 抜け球 0.16 → 0.31、回またぎ○（救援できる投手）0.08 → 0.20、逃げ球 0.26 → 0.36、ナチュラルシュート 0.03 → 0.11
- 外国人用で「実在にない特能」として対ランナー×を外している箇所があれば外す。

### 1-2. 投手のランク特能
`FOREIGN_PITCHER_RANKED_WEIGHTS` の A・B を減らす（A／B／C／D／E／F／G）。
```
ノビ      1.5／10／30／29／17／5／2.5   （今は 3／14／30／29／17／6／1）
打たれ強さ 0.3／3.5／17／77／3／0.6／0.1  （今は 2／8／17／67.7／4／1／0.3）
対ピンチ   0.2／0.8／10／68／15／2.5／0.3 （今は 1／4／10／68／12／4／1）
対左打者   0.2／2／13／46／33／8／0.8    （今は 1／5／13／46／25／8／2）
```

### 1-3. 野手の走力・年齢・打撃の幅
- `FOREIGN_FIELDER_POSITION_PROFILES` の走力: 外野手 61 → 64、遊撃手 72 → 74。
- `FOREIGN_AGE_WEIGHTS["野手"]` を1.5歳若くする（今の重みを、年齢+1.5歳の値で引き直す）。
- ミートとパワーの共通の打撃因子（`hitting`）の掛け目を大きくする: パワー 3.4 → 5.0、ミート 4.2 → 6.0（`power_dev` の式の 3.4 も同じ値にそろえる）。幅と相関の両方が実在に近づく。

### 1-4. 乱数
- 新しい乱数は使わない。候補の確率や重みを変えるだけなので、引く回数はほぼ変わらない（対ランナー×の候補が1つ増えるぶん、引く回数が1つ増える）。外国人の後の抽選がずれるのは受け入れる。変わった項目を一覧で報告する。

### 1-5. 試作した結果（出発点）

container の作業コピーで、1-1〜1-3 を試作した（球団生成300球団、`PYTHONHASHSEED=0`）。**この値を出発点にして、2章の判定で微調整する**。

- 野手の走力は、2022〜26年版（57.6）と 2024〜26年版（59.5）の間を目安にする。外野手はまだ少し低い。
- 球団の野手力が少し上がる（303.1 → 304.3）。`validate_team_mode.py` の戦力レベル (b)（中位が実在±3%）と、野手力の90%点の判定を確かめる。

## 2. 判定

### 2-1. 外国人の判定（`scripts/check_foreign_balance.py`）
- 今の判定の実在の基準が古い年版（2022〜2025年版など）のままなら、2024〜2026年版に合わせ直す（日本人の判定と同じ基準）。合わせ直す項目と理由を報告する。人数が少なく誤差が大きい項目は、PR #110 の仕組みどおり誤差つきで判定する。
- 次の項目を「実在」の判定として足す（2024〜2026年版、球団生成300球団の外国人と個別生成の助っ人外国人用）。

| 項目 | 合格の範囲 |
|---|---|
| 投手 赤特の数 | 実在±0.15 |
| 投手 ランク点 | 実在±1.0 |
| 投手 対ランナー×／対ランナー の保有率 | 実在±0.05 |
| 投手 抜け球・回またぎ○・逃げ球・ナチュラルシュートの保有率 | 実在±0.07 |
| 野手 走力の平均 | 57〜61 |
| 野手 走力 外野手・遊撃手 | 実在（2022〜26）±4（誤差つき） |
| 野手 年齢の平均 | 実在±0.8 |
| 野手 ミート・パワーの SD | 実在の 0.80〜1.15 倍 |

### 2-2. 既存の判定の扱い
- `run_checks.py` を正式な規模で、全スクリプトを単独で流す。
- 外国人の値と、それに続く査定・戦力・背番号で「悪化」が出るのは想定内。悪化の一覧を全部確認し、**動いてよい項目／いけない項目**に分けて報告する。動いてよい項目だけ `--update-snapshot --only ... --reason` で更新する。値が動いたスクリプトは漏れなく更新し、最後に悪化0・改善0を確かめる。
- 動いてはいけない項目（架空球団用の日本人・ドラフト候補用の値）が動いた場合は、更新せずに報告して相談する。
- 特に確認する既存の判定:
  - `check_foreign_balance.py` の既存の項目（能力の分布、特能、ランク、ポジション・打席の割合など）。
  - `validate_team_mode.py` の戦力レベル (a)〜(f)、球団ごとの散らばり、野手力の90%点、外国人の人数・背番号。
- 「固定」の基準値を更新する場合は `--update-baselines --only` で項目を絞り、理由を付ける。

### 2-3. 変わらないことの確認
- 架空球団用の日本人の投手と野手、ドラフト候補用の投手と野手: seed 1〜1000 で完全に一致。
- 球団生成: 日本人の選手は、能力・特能・ランク特能が改修前と一致する（背番号は査定順で変わってよい）。
- 助っ人外国人用: 変わった項目を人数つきで一覧にする。
- `tests/test_hash_independence.py` が通ること。全テストを流し切り、成功・失敗の件数を報告する（失敗0件にしてから報告する）。外国人のテストの固定値は、理由を書いて更新してよい。
