# 外国人の要注意6件 改修指示

## 目的

PR #121 で外国人の判定の実在を2024〜2026年版に入れ替えた結果、要注意になった6件を直す。

| 判定 | 区分 |
|---|---|
| コントロール×スタミナの相関 | 投手 |
| パワー×守備力の相関 | 野手 |
| パワー55未満の割合 | 野手 |
| パワー85以上の割合 | 野手 |
| 遊撃手の割合 | 野手 |
| 右投右打の割合 | 野手 |

対象は助っ人外国人用（個別生成と、球団生成の中の外国人）。架空球団用の日本人・ドラフト候補用は変えない。

**前提**: PR #121 をマージした後の main（d61a162）で作業する。

## 0. 調査の結果

助っ人外国人用の個別生成（投手・野手 各3000人、seed 1〜3000、`PYTHONHASHSEED=0`）と、実在の外国人（2024〜2026年版 投手122人・野手102人。人数が少ないので2022〜2026年版 投手208人・野手172人も並べた）を比べた。

### 0-1. 投手: コントロール×スタミナ

| | 生成 | 実在 2024〜26 | 実在 2022〜26 |
|---|---|---|---|
| 全体 | 0.33 | 0.53 | 0.49 |
| 先発 | 0.11 | 0.37 | 0.38 |
| 救援 | 0.10 | 0.24 | 0.24 |

- 役割の中での結びつきが弱い。年版によらず同じ傾向。
- 原因: `foreign_pitcher_stamina` で、コントロールがスタミナに効く掛け目が 0.08 と小さい。

### 0-2. 野手: パワー

| | 生成 | 実在 2024〜26 | 実在 2022〜26 |
|---|---|---|---|
| パワーの SD | 9.4 | 11.5 | 10.3 |
| 5%／10%／25%点 | 52／56／63 | 39／51／64 | 48／57／63 |
| 中央／75%／90%／95%点 | 70／76／81／83 | 70／75／78／80 | 70／75／78／80 |
| 55未満／85以上 | 7.7%／3.2% | 10.8%／2.0% | 8.1%／1.2% |
| パワー×守備力の相関 | −0.29 | −0.15 | −0.16 |

- 実在は弱い側の裾が長く、強い側は80前後で頭打ち。生成は弱い側が短く、強い側が長い。
- パワー×守備力: `foreign_fielder_abilities` で、守備力をパワーの高さで下げる掛け目（−0.22）が強すぎる。ポジションによる差（遊撃手はパワーが低く守備力が高い）だけで、実在の負の相関はほぼ出る。

## 1. 改修の内容（助っ人外国人用だけ）

### 1-1. 投手のコントロール×スタミナ
- `foreign_pitcher_stamina` の、コントロールをスタミナに効かせる掛け目を役割で分けて大きくする: 先発 0.08 → 0.24、救援 0.08 → 0.18。
- 先発のスタミナの散らばり（`sd_low`・`sd_high`）を 5.8 → 5.5 にして、スタミナ全体の幅を保つ。
- ロングリリーフ枠（中継ぎ×スタミナ型）は今のまま。

### 1-2. 野手のパワーの形と、パワー×守備力
- `foreign_fielder_split_normal` に渡すパワーの散らばりを、下側 6.4 → 8.5、上側 4.4 → 3.6 にする（弱い側の裾を長く、強い側を短く）。下側を広げると平均が下がるので、平均に +1.2 足して戻す。
- 守備力をパワーの高さで下げる掛け目（`fielding_mean` の `- 0.22 * power_dev`）を 0 にする。
- 走力・肩力の、パワーの高さによる下げ（−0.35・−0.18）は変えない。

### 1-3. 野手のポジションと打席
- `FOREIGN_FIELDER_POSITION_TARGETS`: 一塁手 28 → 26、遊撃手 9.5 → 12.5（ほかは今のまま）。
- `FOREIGN_FIELDER_BAT_SIDE_WEIGHTS["右投"]`: 右打 77.5 → 82、両打 9.5 → 5（左打 13 は今のまま）。

### 1-4. 乱数
- 新しい乱数は使わない。重み・掛け目・散らばりを変えるだけなので、引く回数は変わらない（散らばりを変えると、範囲の外で引き直す回数は変わることがある）。

### 1-5. 試作した結果（出発点）

container の作業コピーで、1-1〜1-3 を試作した（助っ人外国人用の個別生成、投手・野手 各3000人）。**この値を出発点にして、2章の判定で微調整する**。

| 項目 | 実在 2024〜26 | 実在 2022〜26 | 改修前 | 試作 |
|---|---|---|---|---|
| コントロール×スタミナ 全体 | 0.53 | 0.49 | 0.33 | 0.46 |
| 〃 先発／救援 | 0.37／0.24 | 0.38／0.24 | 0.11／0.10 | 0.36／0.25 |
| スタミナの平均 先発／救援 | 59.8／46.2 | 59.6／47.8 | 59.2／48.1 | 59.3／48.1 |
| パワーの SD | 11.5 | 10.3 | 9.4 | 10.0 |
| パワー 5%／10%／中央／95%点 | 39／51／70／80 | 48／57／70／80 | 52／56／70／83 | 51／55／70／84 |
| パワー 55未満／85以上 | 10.8%／2.0% | 8.1%／1.2% | 7.7%／3.2% | 9.8%／3.5% |
| パワー×守備力 | −0.15 | −0.16 | −0.29 | −0.21 |
| 遊撃手／一塁手 | 15.7／26.5% | 11.6／25.6% | 9.6／29.3% | 13.0／27.0% |
| 右投右打／右投両打 | 78.4／2.9% | 75.6／6.4% | 70.1／9.5% | 75.1／5.3% |

試作で残った課題（正式版で調整する）:
- **パワー85以上が多い**（3.5%）。平均に足す値（+1.2）を小さくする、上側の散らばりをさらに小さくする（3.6 → 3.0 など）、上限（88）を下げる、のどれかで、中央（70）を保ったまま85以上を2%前後にする。
- パワー×守備力（−0.21）はまだ実在より負が強い。ポジションの割合を直したぶんでも動くので、正式版で測り直す。足りなければ、アーキタイプの補正（長打型の守備力 −1、守備型のパワー −2.5）を少し弱める。
- 救援のスタミナの平均（48.1）が実在（2024〜26 46.2、2022〜26 47.8）より少し高い。今回は直さない。

## 2. 判定

### 2-1. 対象の判定（`scripts/check_foreign_balance.py`）
- 要注意の6件が、合格になること。範囲は PR #121 で決めた「実在から決める」範囲のまま変えない。
- 合格にならない項目があれば、範囲を動かさずに、値と範囲を報告する。

### 2-2. 既存の判定の扱い
- `run_checks.py` を正式な規模で、全スクリプトを単独で流す。
- 外国人の値と、それに続く査定・戦力・背番号、球団生成の日本人の再抽選（PR #121 と同じ仕組み）で値が動くのは想定内。悪化の一覧を全部確認し、**動いてよい項目／いけない項目**に分けて報告する。動いてよい項目だけ `--update-snapshot --only ... --reason` で更新する。値が動いたスクリプトは漏れなく更新し、最後に悪化0・改善0を確かめる。
- 動いてはいけない項目（個別生成の架空球団用の日本人・ドラフト候補用）が動いた場合は、更新せずに報告して相談する。
- 特に確認する既存の判定:
  - `check_foreign_balance.py` のほかの項目（能力の平均・幅、ポジションごとの能力、特能、ランク、サブポジ）。
  - `validate_team_mode.py` の戦力レベル・散らばり・外国人の人数と背番号。
- 「固定」の基準値を更新する場合は `--update-baselines --only` で項目を絞り、理由を付ける。

### 2-3. 変わらないことの確認
- 個別生成の架空球団用の日本人の投手と野手、ドラフト候補用の投手と野手: seed 1〜1000 で完全に一致。
- 球団生成の日本人は、PR #121 と同じく、外国人の年齢帯・ポジションの人数が変わった球団だけ再抽選になってよい。球団全体の年齢帯の割合が変わらないことを確かめる。
- 助っ人外国人用: 変わった項目を人数つきで一覧にする。
- `tests/test_hash_independence.py` が通ること。全テストを流し切り、成功・失敗の件数を報告する（失敗0件にしてから報告する）。外国人のテストの固定値は、理由を書いて更新してよい。
