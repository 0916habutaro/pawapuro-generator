# 斜め方向2球種バーの段違い修正 指示（Codex向け）

対象：`app.py` の変化球チャート（`pitch_bar_shape` / `layout_pitch_chart`）のみ。
他の能力表示パーツ、ラベル配置ロジック、左右反転ロジックには触れないこと。

> **仕様変更**：`変化球表示_改修指示.md` §6 の「斜め2本：外側の列が1セル分先端方向にずれる」は廃止する。
> 斜め2列も、横・下方向の2列と同じく **根元・先端・セル境界をそろえる**。

## 1. 現象

- 斜め方向（カーブ `2` ／シンカー `4`）に2球種あるとき、外側の列（lane 1）だけ全体が1セル先端寄りに置かれている。
- そのため根元と先端の両方が階段状になり、矢じりも2つ段違いに並ぶ。1本のバーに見えず、2本がズレて重なったように見える。
- あわせて、斜めバーの根元は常に 1.8u 固定なので、太いバー同士が並ぶと根元の角が隣の横バー・フォークバーに食い込む（最大 約2.6px）。

## 2. 修正方針

1. **段違いをやめる**：斜め2列でも lane 1 を1セルずらさない。2列が同じ位置から始まり、同じ位置で終わる。先端は横・下方向と同じく矢じりが2つ横に並ぶ。
2. **根元を必要なぶんだけ外へ下げる**：段違いをやめると、フォーク側の列の根元がフォークバーに当たる。斜めバーの根元位置を自分と隣のバーの太さから計算し、隣のバーと重ならない最小の距離にする。
   - 周りが全部単体なら従来どおり 1.8u（見た目は変わらない）。
   - 横・フォーク方向のバーは変更しない。

根元位置の結果（u）：

| 状況 | 根元 |
|---|---|
| 全方向単体 | 1.8（変更なし） |
| 斜めだけ2列 | 2.0 |
| 斜め2列＋隣の横 or フォークも2列 | 2.3 |
| 斜め単体＋隣の横 or フォークが2列 | 2.1 |

## 3. 変更内容（差分は `diagonal_pair_fix.diff`）

1. 定数を追加：`PITCH_BAR_CLEARANCE = 0.09`（u）
   - 全方向単体時のすき間（約0.099u）を超えない値。0.1 にすると全単体時でも根元が 0.001u 動く。
2. 関数を追加：
   - `pitch_bar_half_width(paired)`：単体 0.6875u ／ 2列 0.9u を返す。
   - `diagonal_bar_start(direction_code, paired_directions)`：
     - 斜め以外は `PITCH_BAR_START` を返す。
     - 隣の横バーは `axis[0] > 0` なら `1`、それ以外は `5`。フォークは `3`。
     - 根元の角は軸から自分の半幅だけ張り出すので、必要距離 = 自分の半幅 + (隣の半幅 + CLEARANCE) / sin45°。
     - 横側・フォーク側の大きい方と `PITCH_BAR_START` の最大値を返す。
3. `pitch_bar_shape`：
   - 引数 `start_u: float | None = None` を追加。`None` なら従来どおり `PITCH_BAR_START`。
   - 「斜め2列は外側の列が1セル先端寄り」の2行（`start += PITCH_CELL_PITCH * u`）を削除。
4. `layout_pitch_chart`：バー生成時に `diagonal_bar_start(code, paired_directions)` を渡す。
   - ラベル配置・衝突判定はこのバー形状を使うので、ラベルは自動で追従する。
   - 左投げは右投げ基準で計算してから反転する既存の流れのままでよい。

## 4. テスト変更（差分は `diagonal_pair_tests.diff`）

- 削除：`test_diagonal_outer_lane_is_shifted_one_cell_toward_tip`（段違いを前提にしたテスト）
- 追加：
  - `test_paired_lanes_are_not_staggered_in_any_direction`：全方向で2列の根元・先端・7セルの境界がそろう。
  - `test_bars_never_overlap_other_directions`：全方向の球種数 0/1/2 の全組み合わせ × 右投げ・左投げで、方向の違うバー同士が重ならない。
  - `test_diagonal_root_moves_out_only_when_crowded`：周りが単体なら根元は 1.8u のまま、斜め2列なら外へ下がり、2列の根元は同じ位置。
