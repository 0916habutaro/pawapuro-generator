# 野手の走力（年齢・ポジション・打席） 改修指示

## 目的

架空球団用の日本人野手の**走力**を実在に合わせる。全体の平均はほぼ合っているが、次の3つの「中の構成」がずれている。

1. **年齢による変わり方**: 生成は22〜25歳がいちばん速く、30歳を過ぎると急に遅くなる。実在は26〜31歳あたりがいちばん速く、遅くなるのは32歳から。
2. **打席による差**: 実在は同じポジションでも左打者のほうが速い（一塁手で+8、二塁手で+7）。生成はほぼ差がない。
3. **ポジション**: 一塁手が速すぎる（+4.6）。一塁手・捕手・遊撃手は幅が広すぎる。

走力以外の能力、外国人・ドラフト候補用・投手は変えない。

**前提**: PR #112 をマージした後の main（741d7e1）で作業する。

## 1. 改修の内容（`fictional_fielder_abilities` の中だけ）

`fictional_fielder_abilities` に `batting_throwing` を引数として渡す（呼び出し元は `apply_fictional_fielder_balance`）。走力の計算を次のように直す。どれも**22歳以上だけ**にかけ、21歳以下は今のまま（若手の補正の範囲の判定を崩さないため）。

### 1-1. 上側の端
- 70より上を伸ばす倍率 1.25 を小さくする（試作は 1.15）。

### 1-2. ポジションごとの幅と平均
- ポジションごとに、中心 `c` のまわりで `k` 倍に縮め、`d` だけずらす: `走力 = c + k × (走力 − c) + d`
- 定数は1か所にまとめる（例: `FICTIONAL_SPEED_POSITION_TRANSFORM`）。

### 1-3. 年齢のずらし
- 年齢に対して連続に変わるずらし（折れ線。段差を作らない）を足す。
- 定数は折れ線の点の一覧にする（例: `FICTIONAL_SPEED_AGE_SHIFTS`）。

### 1-4. 打席のずらし
- 左打・両打は足し、右打は引く。打席は `batting_throwing` の末尾（「左打」「右打」「両打」）で判定する。
- 定数: `FICTIONAL_SPEED_BATS_SHIFTS`。

### 1-5. 乱数
- 新しい乱数は使わない。走力で決まる特能・ランク特能（盗塁・走塁など）の付け直しで乱数の引く回数が変わり、その後の抽選がずれるのは、これまでと同じく受け入れる。変わった項目を一覧で報告する。

- 球団の野手力の散らばりが少し広がる（標準偏差 11.84 → 12.53）。PR #108 の散らばりの判定に入るか確認する。

## 2. 判定

### 2-1. 新しい判定（新しいスクリプト `scripts/check_fielder_speed.py`、球団生成300球団）
PR #110 の仕組み（「実在」の判定、誤差つきの合否、id）で作る。年齢別の判定は、実在の2つのデータ（2026年版と逆算）を両方使い、**その平均を目標、2つの差の半分を実在側の誤差に足して**判定する。

| 項目 | 目標 | 合格の範囲 |
|---|---|---|
| 全体の平均 | 64.43 | ±0.6 |
| 全体の 5%・25%・中央・75%・95% | 実在 | ±2 |
| ポジションごとの平均 | 実在 | ±1.5 |
| ポジションごとの標準偏差 | 実在 | ±1.5 |
| 打席ごとの平均（右打・左打） | 実在 | ±1.5 |
| 同じポジションの中の左右差（一塁手・二塁手・外野手・捕手） | 実在 | ±3 |
| 年齢帯ごとの差（22〜23 から 36〜 まで、ポジションの平均を引いた値） | 2つの実在の平均 | ±2.5（＋上の誤差） |

- 個別生成（架空球団用・野手5000人）は参考として同じ表を出す。
- `run_checks.py` に組み込む。

### 2-2. 既存の判定の扱い
- `run_checks.py` を正式な規模で流す。
  - 走力・走力で決まる特能・査定・背番号で「悪化」が出るのは想定内。悪化の一覧を全部確認し、**今回の変更で動いてよい項目かどうか**を一つずつ分けて報告する。
  - 動いてよい項目だけ `--update-snapshot --only ... --reason` でスナップショットを更新する。
  - 動いてはいけない項目（投手・外国人・ドラフト候補、走力と関係のない野手の能力）が動いた場合は、更新せずに報告して相談する。
- 特に確認する既存の判定:
  - `check_fictional_balance.py` の野手の判定（走力の分布、走力と特能の連動、盗塁・走塁のランク）。
  - `check_age_profile.py` の若手の判定（21歳以下は変えていないので動かないはず）と、年齢帯ごとの特能・査定。
  - `validate_team_mode.py` の戦力レベル (a)〜(f)、球団ごとの散らばり（野手力・走力）、機動力の目安（国内の野手の走力 +3以上）、背番号。
- 「固定」の基準値を更新する場合は、`--update-baselines --only` で項目を絞り、理由を付ける。

### 2-3. 変わらないことの確認
- 助っ人外国人用・ドラフト候補用の投手と野手、架空球団用の投手: seed 1〜1000 で完全に一致。
- 架空球団用の野手: 名前・年齢・ポジション・投打・走力以外の能力・変化しない特能が改修前と一致する。21歳以下の選手は全項目が一致する。変わった項目を人数つきで一覧にする。
- `tests/test_hash_independence.py` が通ること。
- テストの期待値は、架空球団用の野手と球団生成の分だけ、理由を書いて更新してよい。
