# 外国人野手 生成バランス 改修指示（パワプロ実在データ 2022〜2026 準拠）

ジェネレーターの「助っ人外国人用」野手生成を、実在の外国人野手の傾向に合わせて調整する。
投手については `外国人投手バランス_改修指示.md` を参照。

## 0. 分析の前提（v3：5シーズン版）

- 生成側：`pawapuro_players_filtered_202609301415.csv`（1000人、全員野手・助っ人外国人用）
- 実在側：baseless.org の「デフォルト選手データ」ページ（各シーズンの最新版）。**外国人野手 延べ151人分**。

  | シーズン | 作品・版 | 野手 |
  |---|---|---|
  | 2022 | eBASEBALLパワプロ2022 1.08版 | 32 |
  | 2023 | eBASEBALLパワプロ2022 1.13版 | 32 |
  | 2024 | パワプロ2024-2025 1.07版 | 28 |
  | 2025 | パワプロ2024-2025 1.15版 | 31 |
  | 2026 | パワプロ2026-2027 デフォルト（`pawapuro_players_entry_route_2026.xlsx`） | 28 |

- 5シーズンとも **基本能力・細かいポジション・サブポジ・特殊能力・ランク特能まで揃っている**。体格と年齢は2026だけ。
- 外国人の判定：カタカナ名の選手と、漢字名の外国人（王柏融・林安可・陽柏翔）。日本の学校からドラフトされた選手（リチャード・ブライト・オコエ・ブランドン・イヒネ・ワォーターズ・モイセエフ・エドポロ・モンテル〈日隈モンテル〉・呉念庭 など）は除外。
- 同じ選手が複数年に出てくる（延べ人数）。
- **2026で新しく入った特能**（死球集中・存在感 など）は2026だけで比べる。2026でなくなった特能（威圧感・恐怖の満塁男 など）は生成で使わない。
- 下記の目標値は **目安** として扱う。

## 2. 基本能力

### 2-1. ばらつきを絞る（最優先）

平均はそのままにして、**幅だけ実在に合わせる**。

| 能力 | 生成 5% / 50% / 95%（最高） | 実在 5% / 50% / 95%（最高） | 目標 |
|---|---|---|---|
| パワー | 47 / 70 / 92（100） | 55 / 71 / 81（87） | 標準偏差 **9前後**、上限 **88**。90以上は出さない |
| ミート | 26 / 45 / 68（84） | 29 / 43 / 60（68） | 平均を43〜44に下げ、上限 **70**。65以上は3〜4% |
| 守備力 | 26 / 47 / 72（80） | 31 / 47 / 58（64） | 標準偏差 **9前後**、60以上は2〜3%、上限 **65** |
| 捕球 | 30 / 48 / 65（81） | 32 / 45 / 62（71） | 上限 **70** 前後 |
| 走力 | 33 / 55 / 76（100） | 32 / 54 / 82（88） | 上側を少し広げる。80以上は6%前後（今は2.7%）、上限 **90** |
| 肩力 | 49 / 68 / 88（100） | 43 / 68 / 85（95） | 下側を広げ、上側を絞る。85以上は5%前後 |

- 生成は、どの能力も最高値が100近くまで出ている。実在の外国人野手で80を超えるのは、走力と肩力（とパワーの一部）だけ。
- 「守備職人」タイプの守備力平均が61.8あるのは、外国人としては高すぎる。守備職人でも守備力は **55〜60** くらいにとどめる。

### 2-2. 弾道

- 今は「パワー60未満→弾道2、65〜75→弾道3、80以上→弾道4」とほぼ機械的に決まっている（相関0.85）。
- **パワーを基準にしつつ、確率で1段ずれるようにする**。目標の相関は **0.4〜0.55**。
  - 例：パワーから決めた弾道に対して、25〜30%の確率で±1する。
  - 実在例：ギッテンス（パワー87・弾道2）。弾道4でパワー65〜70の選手もいる。
- 全体の分布：弾道2 **28〜30%**、弾道3 **48〜50%**、弾道4 **22〜23%**、弾道1は0。

### 2-3. 能力どうしの関係

実在外国人の相関に近づける：

| 組み合わせ | 実在 | 生成 | 対応 |
|---|---|---|---|
| ミート × パワー | **+0.37** | +0.06 | 「打てる外国人は両方ある」形。正の相関を入れる |
| パワー × 守備力 | −0.34 | −0.21 | 負の相関を強める |
| パワー × 肩力 | −0.22 | +0.02 | 負の相関を入れる（強打の一塁手・DH型は肩が弱い） |
| パワー × 走力 | −0.32 | −0.36 | 維持 |
| ミート × 肩力 | −0.01 | +0.24 | 相関をなくす |
| ミート × 守備力 | +0.01 | +0.25 | 相関をなくす |

- ミートと守備・肩の相関（+0.24〜0.26）は、「選手格が高いと全能力が一律に上がる」補正が強すぎるのが原因と思われる。**選手格の補正は打撃（ミート・パワー）中心** にする。
