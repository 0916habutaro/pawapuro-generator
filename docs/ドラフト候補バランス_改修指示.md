# ドラフト候補 生成バランス 改修指示（パワプロ実在データ 1年目 2022〜2026 準拠）

ジェネレーターの「ドラフト候補用」生成（`category=ドラフト候補用`）を、実在選手の **プロ1年目** の能力に合わせて調整する。

## 0. 分析の前提

- 生成側：`pawapuro_players_filtered_202609302128.csv`（2000人：投手1000・野手1000）
- 実在側：
  - 2026：`pawapuro_players_entry_route_2026.xlsx`（年齢・年数・入団経路（推定）つき）
  - 2022〜2025：baseless.org「デフォルト選手データ」（`実在2022-2025.zip`、年齢・年数なし）
- **1年目の特定方法**：2026の年数から1年目の年を逆算する（1年目の年 = 2027 − 年数）。
  - 年数1 → 2026版、年数2 → 2025版、年数3 → 2024版、年数4 → 2023版、年数5 → 2022版
  - その年のデータから同じ名前の選手を探し、その年の能力を「1年目の能力」とする。1年目の年齢 = 2026の年齢 − (年数 − 1)。
  - 外国人（海外・その他）は除外。照合できたのは **306人（投手167・野手139）**。見つからなかった35人は、ほとんどが育成出身（1年目は支配下データにいない）か、略称が変わった選手。
- 入団経路別の人数（投手／野手）：高卒 46／50、大卒 81／67、社会人 37／21、独立・クラブ 3／1。
  - **独立・クラブとその他は実在の人数が少なすぎるので比較しない**（生成側は大卒〜社会人の中間でよい）。
- 実在データはすべて **支配下で指名された選手**。生成側は育成候補（430人）を除いた **下位〜超上位候補（1570人）** と比べる。以下「生成」は育成候補を除いた数字。
- 実在の入団経路は多くが年齢からの推定（確度「中」）。高卒で社会人に入った選手（入団時21歳前後）などは大卒に分類されている可能性がある。
- 5シーズンの平均はほぼ安定している（投手の球速は毎年150.6〜152.6、野手の走力63〜68、肩力63〜68）。年ごとの差は気にしなくてよい。
- 下記の目標値は **目安** として扱う。

## 6. 確認方法（完了条件）

**5000人**（投手・野手それぞれ2500人以上）を生成し、**育成候補を除いた** 選手で下記を満たすこと。2000人の判定は途中確認用（社会人は人数が少なく、揺れで境界付近の項目がまれに外れる。基準に合わせるために分布を歪めないこと）。
`python check_draft_balance.py <生成CSV>` で全項目を自動判定できる（プロジェクトの `claude/check_draft_balance.py`）。改修の途中でも毎回実行し、不合格が0になるまで繰り返すこと。
