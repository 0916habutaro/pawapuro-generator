# 投手の球速（左右差・先発と救援の差） 改修指示

## 目的

球団分析で「投手全体の球速の平均が実在の最大を超えている」と見えた件を調べた。その結果、**全体の平均は実在とほぼ同じで、本当のずれは球速の「中の構成」にある**と分かった。今回はその構成を実在に合わせる。

- **左投手が速すぎ、右投手が遅すぎる**。実在は左投手のほうが約3.3km/h遅いのに、生成では左右の差がほぼ0。
- **先発と救援の差が小さすぎる**。実在は救援のほうが約2.0km/h速いのに、生成では0.4km/h。

対象は **架空球団用の日本人投手だけ**（個別生成と球団生成の両方）。外国人・ドラフト候補用・野手は変えない。

---

## 0. 調査の結果（改修前の現状）

### 0-1. 球速の全体の平均は合っている

球団生成で300球団（seed 1〜300）を作り、実在（2024〜2026年版、36チーム）と比べた。

| 項目 | 生成 | 実在 |
|---|---|---|
| 投手全体（外国人を含む） | 151.81 | 151.80 |
| 日本人投手 | 151.35 | 151.37 |
| 外国人投手 | 155.97 | 155.81 |
| 球団ごとの平均の 最小／10%／中央／90%／最大 | 149.6／150.8／151.8／152.8／154.1 | 150.2／150.9／151.7／152.8／153.2 |
| 実在の最大を超えた球団の割合 | 4.0% | — |

- 球団分析で見えた 153.4 の球団は、分布の裾に当たったもの。投手王国（球団平均152.4）と強豪（152.1）は球速が高めに出るが、これはチームカラーと戦力レベルの意図どおりの効き方。
- 球団ごとの平均のばらつき（標準偏差）も、生成0.77、実在0.74でほぼ同じ。

### 0-2. ずれているのは左右と役割の構成

日本人投手の球速の平均。実在は2024〜2026年版の日本人1,126人、生成は300球団の日本人9,438人。

| 役割 | 投げ | 生成 | 実在 | 差 |
|---|---|---|---|---|
| 先発 | 右 | 151.18 | 151.39 | −0.21 |
| 先発 | 左 | 151.16 | **148.69** | **+2.47** |
| 救援 | 右 | 151.48 | **153.23** | **−1.75** |
| 救援 | 左 | 151.69 | 149.74 | +1.95 |
| 全体 | 右 | 151.33 | 152.37 | −1.04 |
| 全体 | 左 | 151.42 | 149.11 | +2.31 |

- 実在の左右差（左−右）は、先発で −2.7、救援で −3.5。2022〜2026年版の全年版でも同じ傾向（先発 −2.7、救援 −3.8）で、どの年齢帯でも左投手のほうが遅い。
- 個別生成（架空球団用、seed 1〜4000）でも同じ。先発は右151.0・左150.8、救援は右151.7・左151.8で、左右差がない。つまり**球団生成ではなく、選手1人の生成の問題**。
- 左投手の割合は、生成30.8%、実在30.6%で合っている。
- コントロールとスタミナは左右でおおむね合っている（下の表）。**今回は変えない**。

| 平均 | 先発・右 | 先発・左 | 救援・右 | 救援・左 |
|---|---|---|---|---|
| コントロール 生成／実在 | 55.0／54.5 | 55.5／56.7 | 50.3／48.5 | 50.0／47.0 |
| スタミナ 生成／実在 | 58.7／57.4 | 58.4／55.0 | 47.7／47.1 | 47.3／46.5 |

### 0-3. 原因の場所

- `generate_pitcher_abilities` 以降の球速の処理（`pitcher_base_values`、`apply_pitcher_variance`、`shape_pitcher_speed_distribution`、`apply_fictional_pitcher_age_speed_shape`）は、どれも投げ手（右・左）を見ていない。
- 最後の補正 `apply_fictional_pitcher_balance`（`app.py`）は、役割ごとのずらし `FICTIONAL_PITCHER_ROLE_SHIFTS` だけを持っていて、投げ手を見ていない。
- 先発と救援の差: `FICTIONAL_PITCHER_ROLE_SHIFTS` の球速は 先発 0.0、中継ぎ +0.3 しかない（抑え +4.5 は人数が少ない）。

## 2. 改修の内容（`apply_fictional_pitcher_balance` の中だけを変える）

### 2-1. 役割×投げ手の球速のずらし
- 新しい定数 `FICTIONAL_PITCHER_HAND_SPEED_SHIFTS` を作る。キーは `(役割の区分, 投げ手)` で、区分は「先発」「救援」、投げ手は「右」「左」。
- `FICTIONAL_PITCHER_ROLE_SHIFTS` のずらしを足した後の球速に、このずらしを足す。
- **乱数を新しく使わない**。副乱数の名前空間 `fictional_pitcher_balance_v1` の消費順も変えない。これで、球速以外の値（変化球など）は改修前と同じ乱数の流れのまま決まる。

### 2-2. 投げ手ごとの裾の形
左投手は上側の裾、右投手は下側の裾が実在より長い。既存の `compress_tail` を使い、投げ手ごとに1段ずつ裾を縮める。
- 左投手: 上側（ひざの位置の周辺から上）を縮める。
- 右投手: 下側を縮める。
- ひざの位置と縮める強さは定数にまとめる（`FICTIONAL_PITCHER_HAND_SPEED_TAILS` など）。

### 2-3. コントロールとスタミナは連動させない
- 既存の処理は、球速が1km/h上がるとコントロールを0.75下げ（`FICTIONAL_CONTROL_PER_SPEED`）、スタミナもわずかに動かす。
- **左右のずらしと裾の調整は、この連動計算に入れない**。連動には、ずらし・裾の調整を入れる前の球速を使う。
  - 理由: 左投手の球速を下げた分だけコントロールが上がり、左の救援のコントロールが実在（47.0）からさらに離れてしまう。0-2 の表のとおり、コントロールとスタミナは今の値で合っている。

### 2-4. 21歳以下の補正にも左右差を残す
- 21歳以下は `fictional_young_transform` で幅を縮めて平均をずらしている。このままだと、左右の差も縮められてしまう。
- 球速の役割別のずらし（`FICTIONAL_YOUNG_PITCHER_ROLE_DEVS` の球速の値）に、2-1 のずらしを足して渡す。これで差が縮まずに残る。
- 実在の若手（〜22歳、2026年版）も、右152.4・左149.8で左右差がある。

### 2-5. 先発と救援の差
- 2-1 の表で、先発と救援の差もまとめて合わせる。`FICTIONAL_PITCHER_ROLE_SHIFTS` は変えない（抑えの球速の判定に使われているため）。

### 2-6. 試作した結果（出発点）

container の作業コピーで 2-1〜2-4 を試作し、球団生成200球団で確かめた。**この値を出発点にして、正式な判定（3章）で微調整する**。

```
FICTIONAL_PITCHER_HAND_SPEED_SHIFTS = {
    ("先発", "右"): -0.3, ("先発", "左"): -2.0,
    ("救援", "右"): +1.4, ("救援", "左"): -1.4,
}
# 裾: 左投手は 151.0 より上を 0.55 倍に縮める。右投手は 149.0 より下を 0.6 倍に縮める。
# 適用順: 役割のずらし → 左右のずらし → 既存の裾の調整（148下側0.6、155上側0.5） → 投げ手ごとの裾 → 四捨五入
```

| 項目 | 改修前 | 試作 | 実在 |
|---|---|---|---|
| 先発 右／左 | 151.18／151.16 | 151.47／149.07 | 151.39／148.69 |
| 救援 右／左 | 151.48／151.69 | 153.00／149.93 | 153.23／149.74 |
| 日本人全体 | 151.35 | 151.39 | 151.37 |
| 左の 10%／中央／90% | 146／152／156 | 145／150／153 | 145／149／153 |
| 右の 10%／中央／90% | 146／152／156 | 147／153／157 | 148／152／157 |
| 左で155以上 | 約13% | 4.0% | 3.2% |
| 145以下 | 7.9% | 5.0% | 6.0% |
| 162以上 | 0.14% | 0.46% | 0.09% |
| コントロール（4区分） | — | 改修前から±0.3以内 | — |
| 球団ごとの平均 10%／中央／90% | 150.8／151.8／152.8 | 151.0／151.8／152.8 | 150.9／151.7／152.8 |

試作で残った課題（正式版で直す）:
- 162以上が 0.46% に増え、既存の判定（0.5%以下）ぎりぎり。右の救援の上側の裾を少し縮める。
- 先発・右の標準偏差が 3.44 で、実在の 4.31 より狭い。右の下側の裾を縮めすぎている。
- 右の中央が 153（実在152）。

## 3. 判定

### 3-1. 新しい判定（`scripts/check_fictional_balance.py` に「投手の球速の左右・役割」の節を追加）
個別生成の架空球団用・投手 5000人（seed 1〜5000）で判定する。既存の正式判定と同じ人数。

| 項目 | 合格の範囲 |
|---|---|
| 先発・右、先発・左、救援・右、救援・左 の平均 | 実在（1章）±0.5 |
| 左右差（左−右）の平均 | 先発 −2.7±0.6、救援 −3.5±0.6 |
| 救援−先発の平均 | 右 +1.8±0.6、左 +1.0±0.6 |
| 日本人全体の平均 | 151.37±0.3 |
| 投げ手ごとの 10%・中央・90% | 実在±1 |
| 4区分の標準偏差 | 実在±0.6 |
| 左で155以上 | 6%以下 |
| 4区分のコントロール・スタミナの平均 | 改修前±0.5（変えないことの確認） |

### 3-2. 既存の判定を全部通す
- `scripts/check_fictional_balance.py`（5000人）: 球速145以下 9%以下、162以上 0.5%以下、球速×コントロールの相関 −0.40〜−0.15、抑えの平均153以上、ほか全項目。
- `scripts/check_age_profile.py`（若手の能力、特能の年齢帯）。
- `scripts/validate_team_mode.py`（200球団）: 構成、戦力レベル (a)〜(f)、チームカラーの目安（投手王国を含む）、背番号。左投手の査定が下がるので、特に (b)「中位が実在±3%」と投手王国の目安を確認する。外れたら倍率を直さずに報告し、どうするかを相談する。
- 全テスト。

### 3-3. 球団単位の確認（球団分析と同じ集計で）
- 球団生成で300球団（seed 1〜300）を作り、`generator/team_analysis.py` の集計を使って、投手の球速の球団平均の分布を実在（2024〜2026年版36チーム）と比べる。
  - 生成の10%と90%が、実在の10%・90%から±0.3以内。
  - 実在の最大を超える球団、最小を下回る球団が、それぞれ5%以下。
- 年齢帯×投げ手の球速の平均を、実在（2026年版のみ）と並べて報告する。**今回は直さない**（実在は12球団だけで人数が少ないため）。試作では、30〜33歳の右投手が152.7と、実在の151.3より高かった。

### 3-4. 変わらないことの確認
- 助っ人外国人用・ドラフト候補用の投手と野手、架空球団用の野手: seed 1〜1000 の生成結果が改修前と**完全に一致**する。
- 架空球団用の投手: 名前・年齢・役割・投打・変化球の種類が改修前と一致する。変わるのは球速、球速に連動する値（肩力、球速で決まる特能・ランク特能、査定）だけであることを、差分の項目一覧で示す。
- 球団生成: 選手の顔ぶれ（名前・役割・ポジション）は改修前と一致する。投手の査定が変わるので、背番号の割り当ては変わってよい。
- 既存のテストに架空球団用の投手の球速そのものを固定した期待値があれば、理由を書いて期待値を更新してよい。**ほかのカテゴリの期待値は変えない**。

## 5. 今回やらないこと
- ドラフト候補用の左右差。個別生成では右149.7・左150.0（先発）で左右差がないが、基準になる実在のアマチュアデータがないため、別の改修で扱う。
- 外国人投手の左右差。実在は左155.2・右156.0（左30人）で差が小さく、生成もほぼ同じ。
- 救援のコントロールが実在より高い件（生成50.3／50.0、実在48.5／47.0）。
- 年齢帯ごとの球速の形（3-3 で報告だけ）。
- 総変化量、野手の走力など、球団分析で見つかったほかの調整候補。
