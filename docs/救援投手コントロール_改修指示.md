# 救援投手のコントロール 改修指示

## 目的

架空球団用の日本人投手のうち、**救援投手（中継ぎ・抑え）のコントロールが実在より高い**件を直す。

- 平均が高い（右 +1.8、左 +3.0）。
- それ以上に、**幅が広すぎる**。コントロール60以上の救援投手が実在の約1.6倍、70以上が約2.4倍いる。
- あわせて、コントロールの左右差（実在は先発で左が高く、救援で左が低い）も入れる。仕組みが同じ場所なので、まとめて直す。

対象は **架空球団用の日本人投手だけ**（個別生成と球団生成の両方）。外国人・ドラフト候補用・野手は変えない。球速は前回（PR #106）の値のまま変えない。

---

## 0. 調査の結果（PR #106 マージ後の main、1763e7d）

球団生成で300球団（seed 1〜300）を作り、日本人投手（9,438人）を実在（2024〜2026年版の日本人1,126人）と比べた。

### 0-1. 平均（役割×投げ手）

| コントロール | 生成 | 実在 | 差 |
|---|---|---|---|
| 先発・右 | 54.96 | 54.47 | +0.49 |
| 先発・左 | 55.47 | 56.67 | −1.20 |
| 救援・右 | 50.29 | 48.54 | **+1.75** |
| 救援・左 | 49.96 | 47.01 | **+2.95** |

- 実在の左右差（左−右）: 先発 +2.2、救援 −1.5。生成はどちらも ±0.5 で、左右差がない。
- 生成の内訳: 中継ぎ 50.3、抑え 48.6、先発 55.1。

### 0-2. 分布（救援の幅が広い）

| | 10% | 25% | 中央 | 75% | 90% | 標準偏差 |
|---|---|---|---|---|---|---|
| 救援・右 生成 | 33 | 41 | 51 | 59 | 67 | 12.5 |
| 救援・右 実在 | 36 | 41 | 48 | 54 | 62 | 10.0 |
| 救援・左 生成 | 33 | 41 | 50 | 59 | 66 | 12.5 |
| 救援・左 実在 | 34 | 41 | 46 | 53 | 63 | 11.4 |
| 先発・右 生成 | 36 | 46 | 56 | 64 | 72 | 12.9 |
| 先発・右 実在 | 40 | 46 | 53 | 65 | 71 | 12.7 |
| 先発・左 生成 | 38 | 46 | 56 | 64 | 72 | 12.7 |
| 先発・左 実在 | 39 | 47 | 55 | 65 | 74 | 14.2 |

| 救援投手の割合 | 生成 | 実在 |
|---|---|---|
| コントロール60以上 | 24.8% | 15.6% |
| コントロール70以上 | 5.9% | 2.5% |

- 救援は**上側の裾が長すぎる**（75%・90%が実在より5も高い）。下側も10%で実在より2〜3低く、両側に広い。
- 先発の幅はおおむね実在どおり。

### 0-3. 原因の場所
- 救援の高いコントロールは、主に `position_style` の「制球型中継ぎ」（平均59.8、救援の約24%）と、選手格の上位（スター級61.0、一軍主力級55.6）から来ている。
- 最後の補正 `apply_fictional_pitcher_balance` のコントロールのずらし（`FICTIONAL_PITCHER_ROLE_SHIFTS`）は 先発 +1.5、中継ぎ 0、抑え 0 だけで、幅と左右は調整していない。

### 0-4. 参考（今回は直さない）
- 実在のコントロールは年版ごとに上がっている（先発 2022: 51.9 → 2026: 56.6、救援 47.2 → 48.1）。基準は球団分析の既定と同じ 2024〜2026年版にする。
- 年齢帯別（実在は2026年版のみ）でも、生成の救援は全年齢帯で実在より2〜4高い。今回の補正で全体に下がる。
- **球団単位の先発のコントロールの散らばりが大きい**（球団平均の10〜90%: 生成 50.2〜60.1、実在 52.4〜58.3）。戦力レベルで選手格の構成が変わるためで、今回の範囲外（完了報告で数値だけ出す）。

## 2. 改修の内容（`apply_fictional_pitcher_balance` の中だけ）

### 2-1. 救援の幅を縮める
- 救援投手（中継ぎ・抑え）のコントロールに、中心 `c0` のまわりで `k` 倍に縮める線形変換をかける。
  - `control = c0 + k × (control − c0)`
  - 位置: 役割のずらしと球速との連動（`FICTIONAL_CONTROL_PER_SPEED`）を足した後、既存の下側の裾の調整（`compress_tail(control, 35.0, 0.7)`）の前。
- 先発には変換をかけない。

### 2-2. 役割×投げ手のずらし
- 新しい定数 `FICTIONAL_PITCHER_HAND_CONTROL_SHIFTS` を作る。キーは前回の球速と同じ `(区分, 投げ手)`。2-1 の後に足す。

### 2-3. スタミナは変えない
- 既存の処理は、コントロールが高いほどスタミナを上げる（`FICTIONAL_STAMINA_PER_CONTROL = 0.12`）。
- **スタミナの連動計算には、2-1・2-2 を入れる前のコントロールを使う**。スタミナは今の値で実在とおおむね合っているため。
- 理由はもう1つある。救援のコントロールだけを下げると、先発と救援の差が広がって、コントロール×スタミナの相関が上がる。試作では、既存の判定の上限 +0.58 に対して +0.575 になった（改修前 +0.545、実在 +0.49）。連動を切れば、この上がり方を抑えられる。

### 2-4. 21歳以下
- 21歳以下は `fictional_young_transform` で、年齢ごとの平均（`FICTIONAL_YOUNG_PITCHER_MEANS`）に寄せている。
- 2-2 のずらしは、前回の球速と同じやり方で、コントロールの役割別のずらし（`FICTIONAL_YOUNG_PITCHER_ROLE_DEVS` のコントロールの値）に足して渡す。これで左右差が縮まずに残る。
- 2-1 の縮めは若手の変換の前にかかるので、そのままでよい。若手の救援の平均が下がりすぎないかを3-2で確認する。

### 2-5. 乱数
- 新しい乱数は使わない。
- コントロールが変わると、コントロールで決まる特能（四球・ストライク先行など）の付け直しで、乱数を引く回数が変わることがある。前回と同じく、その結果としてランク特能や体格の抽選がずれるのは受け入れる。変わった項目は一覧で報告する。

### 2-6. 試作した結果（出発点）

container の作業コピーで 2-1・2-2 を試作し（2-3・2-4 はまだ入れていない）、球団生成200球団で確かめた。**この値を出発点にして、3章の正式な判定で微調整する**。

```
# 救援だけ: control = 50 + 0.8 × (control − 50)
FICTIONAL_PITCHER_HAND_CONTROL_SHIFTS = {
    ("先発", "右"): -0.4, ("先発", "左"): +1.1,
    ("救援", "右"): -1.4, ("救援", "左"): -2.8,
}
```

| 項目 | 改修前 | 試作 | 実在 |
|---|---|---|---|
| 先発 右／左 | 54.96／55.47 | 54.37／56.21 | 54.47／56.67 |
| 救援 右／左 | 50.29／49.96 | 48.82／47.37 | 48.54／47.01 |
| 救援・右の 10%／中央／90%、標準偏差 | 33／51／67、12.5 | 34／49／62、10.1 | 36／48／62、10.0 |
| 救援・左の 10%／中央／90%、標準偏差 | 33／50／66、12.5 | 34／48／60、10.0 | 34／46／63、11.4 |
| 救援で60以上／70以上 | 24.8%／5.9% | 14.0%／1.3% | 15.6%／2.5% |
| 日本人全体の平均 | 52.70 | 51.72 | 51.78 |
| 球速×コントロールの相関 | −0.267 | −0.262 | −0.274 |
| コントロール×スタミナの相関 | +0.545 | +0.575 | +0.491 |
| 球団の投手上位13人の査定（中央） | 349.9 | 347.3 | 345.1 |
| 救援の球団平均 10%／中央／90% | 45.5／49.6／54.6 | 44.8／48.1／52.2 | 44.5／48.0／50.8 |

試作で残った課題（正式版で直す）:
- 救援・左の幅が狭くなりすぎた（標準偏差10.0、実在11.4）。左は `k` を大きめに（例: 0.9）するなど、投げ手で `k` を分けてよい。
- 70以上が1.3%と、実在の2.5%より少ない。上側を縮めすぎている。
- コントロール×スタミナの相関が上限の近く（2-3 で対応）。

## 3. 判定

### 3-1. 新しい判定（`scripts/check_fictional_balance.py` に「投手のコントロールの役割・左右」の節を追加）
個別生成の架空球団用・投手 5000人（seed 1〜5000）で判定する。

| 項目 | 合格の範囲 |
|---|---|
| 4区分（先発・救援×右・左）の平均 | 実在（1章）±0.8 |
| 左右差（左−右） | 先発 +2.2±1.0、救援 −1.5±1.0 |
| 救援−先発 | 右 −5.9±1.0、左 −9.7±1.5 |
| 救援の標準偏差（右・左） | 実在±1.0 |
| 救援の 10%・中央・90%（右・左） | 実在±2 |
| 救援で60以上 | 12〜19% |
| 救援で70以上 | 1.5〜4% |
| 日本人全体の平均 | 51.78±0.5 |
| 4区分のスタミナの平均 | 改修前±0.3（変えないことの確認） |

- 前回追加した「コントロール・スタミナが改修前と同じ」の判定（`check_fictional_balance.py` の「左右の球速の調整で変わっていないことの確認用」とコメントのある改修前の値と、その比較）は、**スタミナだけを残し、コントロールは今回の新しい判定に置き換える**。
- 前回の球速の判定（4区分の平均、左右差など）は全部そのまま合格すること。

### 3-2. 既存の判定を全部通す
- `scripts/check_fictional_balance.py`（5000人）: コントロール20未満 1%以下、球速×コントロールの相関 −0.40〜−0.15、コントロール×スタミナの相関 +0.38〜+0.58、ほか全項目。
- `scripts/check_age_profile.py`: 若手の能力（21歳以下のコントロール）を含む全項目。
- `scripts/validate_team_mode.py`（200球団）: 構成、戦力レベル (a)〜(f)、チームカラーの目安、背番号。
  - 救援の査定が下がるので、(b)「中位が実在±3%」と「投手王国」の目安を特に確認する。試作では投手上位13人の査定の中央が 349.9 → 347.3 に下がり、実在（345.1）に近づいた。
  - 外れたら、倍率を直さずに報告して相談する。
- 全テスト。

### 3-3. 球団単位の確認（球団分析と同じ集計で、300球団）
- 救援のコントロールの球団平均の 10%・90% が、実在の10%・90%から±1.0以内。
- 先発のコントロールの球団平均の分布も並べて報告する（0-4 の散らばりの件。直さない）。
- 年齢帯×役割のコントロールを、実在（2026年版のみ）と並べて報告する（直さない）。

### 3-4. 変わらないことの確認
- 助っ人外国人用・ドラフト候補用の投手と野手、架空球団用の野手: seed 1〜1000 で改修前と完全に一致する（ドラフト候補用の野手は、前回と同じく同じ `PYTHONHASHSEED` で比べる）。
- 架空球団用の投手: 名前・年齢・役割・投打・球速・変化球の種類が改修前と一致する。変わった項目を人数つきで一覧にする（コントロール、コントロールで決まる特能、それに続く抽選のずれ）。
- 球団生成: 顔ぶれ（名前・役割・ポジション・投打・年齢）は一致。背番号は変わってよい。
- テストの期待値は、架空球団用の投手と球団生成の分だけ、理由を書いて更新してよい。
