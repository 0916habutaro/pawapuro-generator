# 投手の役割（先発・救援）と特能 改修指示

## 目的

架空球団用の日本人投手の特能を、**役割（先発・救援）ごとに**実在に合わせる。

実在では、特能の付き方が先発と救援ではっきり違う。生成は、PR #117 の「青特の型」で投げ手（左・右）の差は入ったが、役割の差が入っていない。そのため、次のような役割に合わない付き方が出ている。

- 救援に多いはずの「緊急登板○」が先発にも付く（生成 先発 6.6%、実在 2.4%）。
- 先発に多いはずの「スロースターター」「負け運」が救援にも付く（救援の負け運 生成 5.7%、実在 0.2%）。
- 救援に多いはずの「奪三振」「球速安定」が、先発と救援で同じくらい。

あわせて、先発の査定が実在より高く（+5）、救援が低い（−3）ずれのうち、特能の分（先発 +1.5、救援 −1.1）が直る。

対象は架空球団用の日本人投手（個別生成・球団生成の両方）。野手、外国人、ドラフト候補用、能力・変化球・ランク特能は変えない。

**前提**: PR #119 をマージした後の main（ad76c5a）で作業する。

---

## 0. 調査の結果

球団生成300球団（seed 1〜300、`PYTHONHASHSEED=0`、main ad76c5a）の日本人投手と、実在（2024〜2026年版の日本人投手）を比べた。

### 0-1. 査定のずれの内訳（生成 − 実在）

| | 査定 | 球速の点 | コントロール・スタミナの点 | ランク特能の点 | 特能の点 | その他（変化球・適性） |
|---|---|---|---|---|---|---|
| 先発 | +5.1 | +2.2 | 0.0 | +0.3 | +1.5 | +1.2 |
| 救援 | −2.9 | −1.7 | −0.3 | 0.0 | −1.1 | +0.1 |

- 球速の点のずれは、平均の球速のわずかな差（先発 +0.4km/h、救援 −0.3km/h）による。役割×投げ手ごとの球速は実在±0.3km/h に入っている（PR #106 の判定の範囲内）ので、今回は変えない（4章）。
- 特能の点のずれが、役割ごとの特能の付き方の違い。

### 0-2. 役割で差の大きい特能（保有率、生成 → 実在）

| 特能 | 先発 | 救援 |
|---|---|---|
| 緊急登板○ | 6.6% → 2.4% | 10.2% → 16.1% |
| 牽制○ | 11.4% → 20.8% | 11.0% → 6.0% |
| 内角攻め | 15.3% → 20.2% | 15.9% → 9.4% |
| スロースターター（赤） | 13.9% → 20.4% | 7.7% → 1.8% |
| 負け運（赤） | 4.1% → 6.3% | 5.7% → 0.2% |
| 緩急○ | 17.6% → 19.9% | 15.4% → 7.8% |
| ナチュラルシュート | 7.5% → 7.7% | 7.6% → 11.8% |

能力と連動させている特能（`FICTIONAL_LINKED_SPECIALS`）も、同じ球速で役割の差がある（球速の帯 〜147／〜151／〜155／156〜）:

| | 生成 先発 | 実在 先発 | 生成 救援 | 実在 救援 |
|---|---|---|---|---|
| 奪三振 | 9／19／25／60% | 7／10／20／62% | 11／17／27／60% | 17／28／33／62% |
| 球速安定 | 24／23／30／38% | 23／13／27／22% | 27／22／28／29% | 46／32／35／39% |

- 原因: 青特の型の補正（`fictional_special_profile_adjust`）の投手の区分が投げ手だけで、役割を見ていない。赤特は補正の対象外。連動特能の保有率（`FICTIONAL_LINKED_HAND_RATES`）も投げ手だけ。

## 1. 改修の内容

### 1-1. 青特の型の補正の投手の区分を「投げ手 × 役割」にする
- `fictional_special_segment` の投手の区分を、緑特の型（PR #118）と同じ「左・右|先発・救援」にする（中継ぎ・抑えは救援）。
- 投手の表を `scripts/build_fictional_special_profile.py` で作り直す。作り方は PR #117 と同じ（`w = n/(n+60)` で縮め、投げ手の倍率 × 役割の倍率。水準は生成の今の全体の保有率。1回だけ結果を見て直す）。
- **投手の赤特も表に入れる**（スロースターター・負け運・一発・乱調・寸前・軽い球・抜け球など。実在で10人以上が持つもの）。水準は生成の今の全体の保有率のまま（赤特の数を変えない）。
  - 能力と連動させる赤特（四球・荒れ球）は入れない。
  - 対ランナー（青）・対ランナー×（赤）は、今までどおり水準も実在にする。
- 野手の表は変えない。
- 右投手のクロスファイヤーを必ず外す決まりは、そのまま残す。
- 補正の段階・乱数の名前空間（`fictional_special_profile_v1`）は今のまま。表の特能が増えるので乱数を引く回数は増えるが、副乱数なので、ほかの抽選の並びは変わらない。

### 1-2. 連動特能の保有率を役割でも分ける
- `FICTIONAL_LINKED_HAND_RATES` の投手の指定を、「投げ手|役割」でも引けるようにする（「左|救援」などがあればそれを使い、なければ今の「左」「右」を使う）。
- `fictional_adjust_specials` と `fictional_age_adjust_specials` の両方で、投手は「投げ手|役割」を渡す。
- 乱数を引く回数は変えない。PR #117 の「共有の乱数の空回し」（改修前の計算を乱数を進めるためだけに回す部分）の引数は変えない。

```
奪三振（球速 〜147／〜151／〜155／156〜）:
  右|先発 0.045／0.07／0.15／0.62    右|救援 0.07／0.21／0.28／0.61
  左|先発 0.09／0.15／0.45／0.70     左|救援 0.20／0.40／0.60／0.80
球速安定（同じ帯）:
  先発（左右とも）0.23／0.15／0.26／0.24
  救援（左右とも）0.45／0.32／0.35／0.38
```

## 2. 判定

### 2-1. 新しい判定（球団生成300球団、架空球団用の日本人投手）
PR #117 の `scripts/check_special_profile.py` に節を足す（PR #110 の仕組み）。

| 項目 | 合格の範囲 |
|---|---|
| 青特の数 先発・救援 | 実在±0.20（実在は○○キラーを数えない） |
| 赤特の数 先発・救援 | 実在±0.12 |
| 0-2 の表の特能の、役割ごとの保有率 | 実在±0.05（人数の少ないものは誤差つき） |
| 奪三振・球速安定の、帯 × 役割ごとの保有率 | 実在±0.08（人数の少ない帯は誤差つき） |
| 特能の査定点の 先発−救援 | 実在（−2.2）±1.5 |

- PR #117 の投げ手ごとの判定（青特の数 左・右、左右差、右投手のクロスファイヤー0人など）は、そのまま合格すること。
- 個別生成（架空球団用・投手5000人）は参考として同じ表を出す。

### 2-2. 既存の判定の扱い
- `run_checks.py` を正式な規模で、全スクリプトを単独で流す。
- 特能・査定・戦力・背番号で「悪化」が出るのは想定内。悪化の一覧を全部確認し、**動いてよい項目／いけない項目**に分けて報告する。動いてよい項目だけ `--update-snapshot --only ... --reason` で更新する。値が動いたスクリプトは漏れなく更新し、最後に悪化0・改善0を確かめる。
- 動いてはいけない項目（投手の能力・変化球・ランク特能、野手、外国人・ドラフト候補）が動いた場合は、更新せずに報告して相談する。
- 特に確認する既存の判定:
  - `check_age_profile.py` の投手の年齢帯ごとの青特・赤特の数と年齢との相関。
  - `check_fictional_balance.py` の特能の出現率・能力との連動（奪三振・球速安定の球速の帯ごとの保有率）・特能数の分布。
  - `validate_team_mode.py` の戦力レベル、散らばり、投手王国の目安、背番号。
- 「固定」の基準値を更新する場合は `--update-baselines --only` で項目を絞り、理由を付ける。

### 2-3. 変わらないことの確認
- 助っ人外国人用・ドラフト候補用の投手と野手、架空球団用の野手: seed 1〜1000 で完全に一致。
- 架空球団用の投手: 名前・年齢・役割・投打・球速・コントロール・スタミナ・変化球・ランク特能・身長・体重が改修前と一致する。変わった項目を人数つきで一覧にする（特能、特能から決まる査定・背番号）。
- `tests/test_hash_independence.py` が通ること。全テストを流し切り、成功・失敗の件数を報告する（失敗0件にしてから報告する）。
